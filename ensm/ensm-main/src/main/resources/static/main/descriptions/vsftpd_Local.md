# 로컬 사용자 접근 허용 (Local Enable)

## 이 옵션이 하는 일

시스템에 등록된 실제 사용자 계정으로 FTP 접속을 허용할지 결정합니다. 활성화하면 Linux 사용자 계정으로 FTP 서버에 로그인할 수 있습니다.

## 동작 방식

### 활성화 시 (ON, 권장)
- 시스템 사용자 계정으로 FTP 로그인 가능
- 각 사용자는 자신의 홈 디렉토리에 접근
- 사용자별 권한 적용

### 비활성화 시 (OFF)
- 로컬 사용자 로그인 불가
- 익명 사용자만 접근 가능 (익명 활성화 시)

## 사용 시나리오

### 활성화가 권장되는 경우
- **파일 공유**: 여러 사용자가 각자의 파일 관리
- **웹 호스팅**: 웹사이트 파일 업로드/다운로드
- **일반적인 FTP 서버**: 대부분의 경우

### 비활성화가 필요한 경우
- **익명 FTP만 제공**: 공개 파일 다운로드만
- **특수한 구성**: 다른 인증 방식 사용

## 알아야 할 것들

### 사용자 계정 생성

FTP 접속을 허용할 사용자 계정을 생성:

```bash
# 사용자 생성
sudo useradd -m -s /bin/bash ftpuser

# 비밀번호 설정
sudo passwd ftpuser

# FTP 디렉토리 권한
sudo chmod 755 /home/ftpuser
```

### 보안 고려사항

**중요**: 
- 강력한 비밀번호 사용
- `chroot_local_user` 활성화 권장 (홈 디렉토리 제한)
- 불필요한 사용자 계정 비활성화

### 홈 디렉토리 제한

`chroot_local_user` 옵션과 함께 사용:
- 사용자를 자신의 홈 디렉토리로 제한
- 시스템 다른 부분 접근 방지
- 보안 강화

## 자주 발생하는 오류

### 로그인이 안 됨
**확인 사항**:
1. 사용자 계정이 존재하는지 확인
2. 비밀번호가 올바른지 확인
3. `local_enable`이 활성화되어 있는지 확인
4. 사용자 홈 디렉토리 권한 확인

### "530 Login incorrect" 오류
**원인**: 
- 사용자명 또는 비밀번호 오류
- 사용자 계정이 잠겨있음
- 셸이 `/sbin/nologin`으로 설정됨

**해결 방법**:
1. 사용자명과 비밀번호 확인
2. 계정 상태 확인: `sudo passwd -S username`
3. 셸 확인: `grep username /etc/passwd`

### 홈 디렉토리에 접근 불가
**원인**: 디렉토리 권한 문제

**해결 방법**:
```bash
# 홈 디렉토리 권한 설정
sudo chmod 755 /home/username
sudo chown username:username /home/username
```
