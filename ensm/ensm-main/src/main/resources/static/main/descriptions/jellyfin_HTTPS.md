# HTTPS 사용 (Enable HTTPS)

## 이 옵션이 하는 일

Jellyfin 웹 인터페이스에 HTTPS 암호화 연결을 사용할지 결정합니다. HTTPS를 사용하면 데이터가 암호화되어 보안이 강화됩니다.

## 동작 방식

### 활성화 시 (ON, 권장)
- HTTPS 연결 사용
- 데이터 암호화
- 보안 강화
- 별도 HTTPS 포트 필요 (기본: 8920)

### 비활성화 시 (OFF)
- HTTP 연결만 사용
- 데이터 암호화 안 됨
- 내부 네트워크에서만 사용 권장

## 사용 시나리오

### 활성화가 권장되는 경우
- **외부 접속**: 인터넷을 통한 접속
- **보안**: 민감한 데이터 전송
- **프로덕션 환경**: 실제 사용 환경

### 비활성화가 가능한 경우
- **내부 네트워크만**: 로컬 네트워크에서만 접속
- **개발 환경**: 테스트 목적
- **임시 사용**: 빠른 설정 필요 시

## 알아야 할 것들

### SSL/TLS 인증서

HTTPS를 사용하려면 인증서가 필요합니다:
- **자체 서명 인증서**: 개발/테스트용 (브라우저 경고 발생)
- **Let's Encrypt**: 무료 공인 인증서 (권장)
- **상용 인증서**: 유료 인증서

### 포트 설정

HTTPS 사용 시:
- HTTP 포트: 8096 (선택사항, 비활성화 가능)
- HTTPS 포트: 8920 (필수)

### 보안 고려사항

**HTTPS 사용 시**:
- 모든 데이터 암호화
- 중간자 공격 방지
- 로그인 정보 보호

**HTTP만 사용 시**:
- 데이터가 평문으로 전송
- 외부 네트워크에서 위험
- 내부 네트워크에서만 사용 권장

## 자주 발생하는 오류

### "SSL certificate error" 오류
**원인**: 자체 서명 인증서 사용

**해결 방법**:
1. 브라우저에서 인증서 예외 추가
2. 또는 Let's Encrypt 인증서 사용
3. 또는 공인 인증서 사용

### HTTPS 포트로 접속이 안 됨
**확인 사항**:
1. HTTPS 포트가 올바르게 설정되었는지 확인
2. 방화벽에서 HTTPS 포트 열기
3. 인증서가 올바르게 설정되었는지 확인

### 인증서 만료
**원인**: 인증서 유효 기간 만료

**해결 방법**:
1. 인증서 갱신
2. Let's Encrypt는 자동 갱신 설정
3. 새 인증서 설치
