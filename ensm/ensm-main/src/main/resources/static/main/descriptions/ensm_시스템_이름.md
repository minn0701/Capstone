# ENSM 시스템 이름

## 개요

ENSM 시스템의 이름을 지정하는 설정입니다. 대시보드 및 UI에 표시되는 시스템 식별명입니다.

## 설정 방법

시스템 이름을 입력합니다:

```
ENSM
```

또는:

```
My Server
```

## 주요 특징

- **식별명**: 시스템을 식별하는 이름
- **UI 표시**: 대시보드 및 웹 UI에 표시됩니다
- **자유 형식**: 원하는 이름을 지정할 수 있습니다

## 일반적인 사용 예시

```
ENSM
My Server
Production Server
Development Server
```

## 주의사항

- **고유성**: 여러 시스템을 관리하는 경우 고유한 이름을 사용하는 것이 좋습니다
- **특수문자**: 특수문자 사용 시 UI 표시에 영향을 줄 수 있습니다
- **길이**: 너무 긴 이름은 UI 레이아웃에 영향을 줄 수 있습니다

## 권장 설정

시스템의 용도나 환경을 나타내는 이름을 사용하는 것을 권장합니다:

- **프로덕션**: `Production Server`
- **개발**: `Development Server`
- **테스트**: `Test Server`
- **개인**: `My Server` 또는 `Home Server`
