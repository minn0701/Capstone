# SSH 키 타입

## 개요

SSH 키의 암호화 알고리즘 타입을 선택하는 설정입니다. 키 생성 시 사용할 알고리즘을 지정합니다.

## 설정 방법

드롭다운 메뉴에서 키 타입을 선택합니다:

- **RSA**: 전통적인 알고리즘, 호환성이 좋음
- **ED25519**: 최신 알고리즘, 보안성이 높음 (권장)
- **ECDSA**: 타원곡선 알고리즘, 효율적

## 키 타입 비교

### RSA

- **호환성**: 가장 넓은 호환성
- **키 크기**: 2048비트 이상 권장 (4096비트 권장)
- **성능**: 상대적으로 느림
- **보안**: 안정적이지만 오래된 알고리즘

### ED25519 (권장)

- **보안성**: 매우 높은 보안성
- **키 크기**: 고정 256비트 (크기 지정 불필요)
- **성능**: 빠른 키 생성 및 검증
- **호환성**: 최신 시스템에서 지원

### ECDSA

- **효율성**: 작은 키 크기로 높은 보안성
- **키 크기**: 256, 384, 521비트
- **성능**: 빠름
- **호환성**: 대부분의 최신 시스템에서 지원

## 권장 설정

- **새로운 시스템**: ED25519 (최고의 보안성과 성능)
- **오래된 시스템**: RSA 4096비트 (최대 호환성)
- **균형**: ECDSA 521비트 (보안성과 효율성의 균형)

## 주의사항

- **시스템 지원**: 대상 시스템이 선택한 키 타입을 지원해야 합니다
- **키 크기**: RSA는 키 크기를 지정해야 하지만, ED25519는 불필요합니다
- **보안**: 가능하면 ED25519를 사용하는 것을 권장합니다

## 키 타입별 명령어

### RSA

```bash
ssh-keygen -t rsa -b 4096
```

### ED25519

```bash
ssh-keygen -t ed25519
```

### ECDSA

```bash
ssh-keygen -t ecdsa -b 521
```
