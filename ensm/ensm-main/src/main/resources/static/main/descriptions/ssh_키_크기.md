# SSH 키 크기

## 개요

SSH 키의 비트 크기를 지정하는 설정입니다. 키 타입에 따라 사용 가능한 크기가 다릅니다.

## 설정 방법

키의 비트 크기를 숫자로 입력합니다:

```
2048
```

## 키 타입별 권장 크기

### RSA

- **최소**: 2048비트
- **권장**: 4096비트
- **최대**: 16384비트 (일반적으로 불필요)

### ED25519

- **크기 지정 불필요**: 고정 256비트
- **설정 무시**: 키 크기 설정이 무시됩니다

### ECDSA

- **256비트**: 일반적인 사용
- **384비트**: 높은 보안성
- **521비트**: 최고 보안성 (권장)

## 일반적인 사용 예시

```
# RSA
2048
4096

# ECDSA
256
384
521
```

## 보안 고려사항

- **RSA**: 2048비트는 최소 요구사항, 4096비트 권장
- **ED25519**: 크기 지정 불필요 (항상 256비트)
- **ECDSA**: 521비트 권장

## 주의사항

- **ED25519**: 키 크기 설정이 무시됩니다 (고정 256비트)
- **성능**: 큰 키 크기는 키 생성 및 검증 시간이 증가합니다
- **호환성**: 일부 오래된 시스템은 큰 키 크기를 지원하지 않을 수 있습니다

## 권장 설정

- **RSA**: 4096비트
- **ED25519**: 크기 지정 불필요
- **ECDSA**: 521비트

## 키 크기와 보안

일반적으로 키 크기가 클수록 보안성이 높아지지만, 성능은 저하됩니다:

- **2048비트 RSA**: 현재 안전하지만 향후 취약할 수 있음
- **4096비트 RSA**: 장기적으로 안전
- **ED25519**: 작은 크기로 높은 보안성 (권장)
