# BIND listen-on port 53 설정

## 개요

BIND DNS 서버가 IPv4 주소에서 DNS 쿼리를 수신할 네트워크 인터페이스와 포트를 지정하는 설정입니다. 기본적으로 포트 53을 사용합니다.

## 설정 방법

```named
options {
    listen-on port 53 { 127.0.0.1; };
};
```

또는 모든 인터페이스에서 수신:

```named
options {
    listen-on port 53 { any; };
};
```

## 주요 특징

- **기본 포트**: DNS는 표준적으로 53번 포트를 사용합니다
- **보안**: 특정 IP 주소만 지정하여 외부 접근을 제한할 수 있습니다
- **다중 IP**: 여러 IP 주소를 지정할 수 있습니다

## 일반적인 사용 예시

```named
# 로컬호스트에서만 수신 (보안 강화)
listen-on port 53 { 127.0.0.1; };

# 특정 IP 주소에서 수신
listen-on port 53 { 192.168.1.100; 10.0.0.1; };

# 모든 인터페이스에서 수신
listen-on port 53 { any; };

# 특정 서브넷에서 수신
listen-on port 53 { 192.168.1.0/24; };
```

## 보안 권장사항

1. **최소 권한 원칙**: 필요한 IP 주소만 지정
2. **내부 네트워크**: 가능하면 내부 네트워크 IP만 허용
3. **방화벽**: 방화벽에서도 포트 53 접근을 제한

## 주의사항

- **IPv6**: IPv6 주소는 `listen-on-v6` 지시어로 별도 설정
- **포트 변경**: 표준 포트가 아닌 경우 클라이언트 설정도 변경 필요
- **권한**: 1024 이하 포트 사용 시 root 권한 필요

## 오류 해결

### 포트가 이미 사용 중인 경우

```bash
# 포트 사용 확인
ss -tulpn | grep :53

# BIND 프로세스 확인
systemctl status named
```

### 접근 불가 오류

- 방화벽에서 포트 53이 열려있는지 확인
- SELinux 정책 확인
- `listen-on`에 올바른 IP 주소가 지정되어 있는지 확인
