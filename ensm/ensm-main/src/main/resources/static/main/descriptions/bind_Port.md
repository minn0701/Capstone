# DNS 서버 포트 (Port)

## 이 옵션이 하는 일

BIND DNS 서버가 DNS 쿼리를 받을 포트 번호를 지정합니다. DNS는 기본적으로 53번 포트를 사용하며, 이 포트를 통해 도메인 이름을 IP 주소로 변환하는 요청을 받습니다.

## 기본값

- **기본값**: 53
- **표준 포트**: 53 (DNS 프로토콜 표준)

## 포트 설정

### 표준 포트 (53)
```
53        → 표준 DNS 포트 (권장)
```
→ 모든 DNS 클라이언트가 기본적으로 사용하는 포트

### 대체 포트
```
5353      → mDNS (멀티캐스트 DNS) 포트
8053      → 개발/테스트용 포트
```
→ 특수한 경우에만 사용 (일반적으로 권장하지 않음)

## 알아야 할 것들

### 포트 53의 특수성

- **root 권한 필요**: 1024 이하 포트이므로 root 권한으로 실행해야 함
- **UDP와 TCP 모두 사용**: DNS는 주로 UDP를 사용하지만, 큰 응답은 TCP 사용
- **방화벽 설정 필수**: 외부에서 접근하려면 방화벽에서 포트를 열어야 함

### DNS 쿼리 프로세스

1. 클라이언트가 DNS 서버(53번 포트)에 도메인 이름 질의
2. DNS 서버가 IP 주소를 응답
3. 클라이언트가 해당 IP로 접속

### 보안 고려사항

**포트 53은 공개적으로 접근 가능해야 합니다** (공용 DNS 서버인 경우):
- 내부 네트워크 DNS: 내부에서만 접근 가능하게 설정
- 공용 DNS 서버: 외부 접근 허용 필요

## 자주 발생하는 오류

### "Address already in use" 오류
**원인**: 다른 DNS 서버나 프로그램이 53번 포트를 사용 중

**해결 방법**:
```bash
# 포트 사용 확인
sudo netstat -tulpn | grep :53

# 기존 DNS 서버 중지 (systemd-resolved 등)
sudo systemctl stop systemd-resolved
```

### 외부에서 DNS 쿼리가 안 됨
**확인 사항**:
1. 방화벽에서 53번 포트(UDP, TCP 모두) 열기
2. BIND가 외부 인터페이스에서 수신하도록 설정
3. 라우터 포트 포워딩 확인 (홈 서버인 경우)

### 권한 오류
**원인**: 53번 포트는 root 권한 필요

**해결 방법**:
- BIND는 보통 `named` 사용자로 실행되지만, 시작은 root 권한 필요
- systemd 서비스로 관리하면 자동 처리
