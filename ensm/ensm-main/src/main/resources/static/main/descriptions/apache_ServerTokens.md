# 서버 버전 정보 표시 (ServerTokens)

## 이 옵션이 하는 일

HTTP 응답 헤더에 Apache 서버의 버전 정보를 얼마나 상세하게 표시할지 결정합니다. 보안상 서버 정보를 최소화하는 것이 권장됩니다.

## 선택지 설명

### Full (전체 정보)
- **표시 내용**: Apache 버전, 모듈 정보, OS 정보 등 모든 정보
- **예시**: `Server: Apache/2.4.41 (Ubuntu) PHP/7.4.3`
- **보안**: ⚠️ 취약 (공격자가 공격 방법을 쉽게 파악)
- **사용 시기**: 개발 환경, 디버깅

### OS (OS 정보만)
- **표시 내용**: Apache 버전과 운영체제 정보
- **예시**: `Server: Apache/2.4.41 (Ubuntu)`
- **보안**: ⚠️ 취약
- **사용 시기**: 개발 환경

### Min (최소 정보)
- **표시 내용**: Apache 버전만
- **예시**: `Server: Apache/2.4.41`
- **보안**: ⚠️ 보통
- **사용 시기**: 개발 환경

### Major (주 버전만)
- **표시 내용**: Apache 주 버전만
- **예시**: `Server: Apache/2`
- **보안**: ✅ 양호
- **사용 시기**: 일반 운영 환경

### Minor (부 버전만)
- **표시 내용**: Apache 부 버전까지
- **예시**: `Server: Apache/2.4`
- **보안**: ⚠️ 보통
- **사용 시기**: 일반 운영 환경

### Prod (정보 숨김, 권장)
- **표시 내용**: Apache만 표시 (버전 정보 없음)
- **예시**: `Server: Apache`
- **보안**: ✅ 최고 (권장)
- **사용 시기**: **프로덕션 환경에 권장**

## 보안 고려사항

### 왜 정보를 숨겨야 하나요?

서버 정보가 노출되면:
- 공격자가 특정 버전의 취약점을 악용할 수 있음
- 사용 중인 모듈 정보로 공격 방법 파악 가능
- 불필요한 정보 노출로 보안 위험 증가

### 권장 설정

**프로덕션 환경**: `Prod` (권장)
- 최소한의 정보만 노출
- 보안 모범 사례 준수

**개발 환경**: `Full` 또는 `OS`
- 디버깅에 유용
- 문제 해결 시 도움

```bash
# curl로 확인
curl -I http://example.com

# 또는 브라우저 개발자 도구에서
# Network 탭 → Response Headers 확인
```

### ServerTokens와 ServerSignature

- **ServerTokens**: HTTP 응답 헤더의 `Server` 필드 제어
- **ServerSignature**: 오류 페이지 하단의 서버 정보 제어

둘 다 `Prod`로 설정하는 것이 좋습니다.

### 모듈 정보 숨기기

`ServerTokens Prod`로 설정해도 일부 모듈은 여전히 정보를 노출할 수 있습니다. 추가 설정이 필요할 수 있습니다.

## 자주 발생하는 오류

### 보안 스캔에서 경고 발생
**원인**: `ServerTokens`가 `Full` 또는 `OS`로 설정됨

**해결 방법**:
1. `Prod`로 변경
2. Apache 재시작
3. 보안 스캔 재실행

### 정보가 여전히 노출됨
**확인 사항**:
1. `ServerTokens Prod` 설정 확인
2. Apache 재시작 또는 설정 리로드
3. 캐시 클리어 후 다시 확인

### 개발 환경에서 정보가 필요함
**해결 방법**:
- 개발 환경에서는 `Full` 또는 `OS` 사용 가능
- 프로덕션 환경으로 전환 시 `Prod`로 변경
