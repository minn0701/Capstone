# DDNS 활성화

## 개요

Cloudflare DDNS 자동 업데이트 기능을 활성화하는 설정입니다. 동적 IP 주소를 가진 서버의 IP가 변경될 때 자동으로 Cloudflare DNS 레코드를 업데이트합니다.

## 설정 방법

체크박스를 통해 활성화/비활성화합니다:

- ✅ 체크: DDNS 자동 업데이트 활성화
- ❌ 체크 해제: DDNS 기능 비활성화

## 주요 특징

- **자동 업데이트**: IP 주소 변경 시 자동으로 DNS 레코드 업데이트
- **Cloudflare 연동**: Cloudflare DNS를 사용하여 동적 DNS 관리
- **CRON 스케줄**: 정기적으로 IP 주소를 확인하고 업데이트

## 활성화 시 필요 설정

DDNS를 활성화하려면 다음 설정이 필요합니다:

- **Cloudflare API 토큰**: Cloudflare API 접근을 위한 토큰
- **Zone 이름**: Cloudflare에 등록된 도메인
- **레코드 이름**: 업데이트할 DNS 레코드 이름
- **TTL**: DNS 레코드의 TTL 값
- **업데이트 주기**: CRON 형식의 업데이트 주기

## 주의사항

- **API 토큰**: 유효한 Cloudflare API 토큰이 필요합니다
- **권한**: API 토큰에 DNS 편집 권한이 있어야 합니다
- **네트워크**: Cloudflare API에 접근할 수 있어야 합니다

## 사용 시나리오

- **동적 IP**: ISP에서 동적 IP를 할당받는 경우
- **홈 서버**: 집에서 운영하는 서버의 IP가 자주 변경되는 경우
- **원격 접속**: 외부에서 서버에 접속하기 위해 도메인을 사용하는 경우
