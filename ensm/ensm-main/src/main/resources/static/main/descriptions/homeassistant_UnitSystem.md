# 단위 시스템 (Unit System)

## 이 옵션이 하는 일

Home Assistant에서 사용할 측정 단위 시스템을 지정합니다. 온도, 거리, 속도 등의 단위가 결정됩니다.

## 선택지 설명

### metric (미터법)
- **의미**: 미터, 킬로그램, 섭씨 등
- **사용 시기**: **대부분의 국가** (한국 포함)
- **예시**: 온도(°C), 거리(km), 속도(km/h)

### imperial (야드파운드법)
- **의미**: 피트, 파운드, 화씨 등
- **사용 시기**: 미국, 영국 등
- **예시**: 온도(°F), 거리(mi), 속도(mph)

## 알아야 할 것들

### 단위 변환

설정한 단위 시스템에 따라:
- 모든 측정값이 해당 단위로 표시
- 센서 데이터도 해당 단위로 변환
- 자동화 스크립트에도 영향

### 지역별 사용

- **미터법**: 한국, 유럽, 대부분의 국가
- **야드파운드법**: 미국, 영국

## 자주 발생하는 오류

### 단위가 잘못 표시됨
**원인**: 단위 시스템 설정 오류

**해결 방법**:
1. 올바른 단위 시스템 선택
2. Home Assistant 재시작
3. 센서 설정 확인
