# 고도 (Elevation)

## 이 옵션이 하는 일

Home Assistant 서버의 해발 고도를 미터 단위로 지정합니다. 날씨 정보, 기압 계산 등에 사용됩니다.

## 기본값

- **기본값**: 0 (해수면)
- **형식**: 정수 (미터)

## 설정 예시

### 해수면
```
0
```

### 일반적인 고도
```
50
100
```

### 높은 고도
```
500
1000
```

## 알아야 할 것들

### 사용 용도

고도는 다음에 사용됩니다:
- 날씨 정보 (기압 보정)
- 환경 센서 데이터
- 위치 기반 자동화

### 정확도

대략적인 값으로도 충분합니다:
- 정확한 고도보다는 대략적인 값
- 날씨 정보에 약간의 영향

## 자주 발생하는 오류

### 날씨 정보가 부정확함
**원인**: 고도 설정 오류 (일부 영향)

**해결 방법**:
1. 대략적인 고도 설정
2. 날씨 서비스 설정 확인
