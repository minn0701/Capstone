# FTP 서버 포트 (Port)

## 이 옵션이 하는 일

vsftpd FTP 서버가 클라이언트의 연결 요청을 받을 포트 번호를 지정합니다. FTP는 기본적으로 21번 포트를 사용합니다.

## 기본값

- **기본값**: 21
- **표준 포트**: 21 (FTP 프로토콜 표준)

## 포트 설정

### 표준 포트 (21)
```
21        → 표준 FTP 포트 (권장)
```
→ 모든 FTP 클라이언트가 기본적으로 사용하는 포트

### 대체 포트
```
2121      → 개발/테스트용 포트
8021      → 대체 포트
```
→ 특수한 경우에만 사용 (일반적으로 권장하지 않음)

## 알아야 할 것들

### FTP의 두 가지 포트

FTP는 두 개의 포트를 사용합니다:
- **포트 21**: 제어 연결 (명령 전송)
- **포트 20**: 데이터 연결 (파일 전송, Active 모드)
- **PASV 모드**: 데이터 연결을 위한 추가 포트 범위 필요

### Active vs Passive 모드

**Active 모드**:
- 클라이언트가 데이터 포트를 열고 서버가 연결
- 방화벽 환경에서 문제 발생 가능

**Passive 모드 (PASV)**:
- 서버가 데이터 포트를 열고 클라이언트가 연결
- 방화벽 환경에서 권장

### 보안 고려사항

**포트 21은 공개적으로 접근 가능해야 합니다** (공용 FTP 서버인 경우):
- 내부 네트워크 FTP: 내부에서만 접근 가능하게 설정
- 공용 FTP 서버: 외부 접근 허용 필요

## 자주 발생하는 오류

### "Address already in use" 오류
**원인**: 다른 FTP 서버나 프로그램이 21번 포트를 사용 중

**해결 방법**:
```bash
# 포트 사용 확인
sudo netstat -tulpn | grep :21

# 기존 FTP 서버 중지
sudo systemctl stop vsftpd
```

### 외부에서 FTP 접속이 안 됨
**확인 사항**:
1. 방화벽에서 21번 포트(TCP) 열기
2. PASV 모드 사용 시 포트 범위도 열기
3. 라우터 포트 포워딩 확인 (홈 서버인 경우)

### 방화벽 환경에서 연결이 끊김
**원인**: Active 모드 사용 시 클라이언트 방화벽 문제

**해결 방법**:
- PASV 모드 사용 권장
- PASV 포트 범위를 방화벽에서 열기
