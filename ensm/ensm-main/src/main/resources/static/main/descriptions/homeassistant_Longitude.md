# 경도 (Longitude)

## 이 옵션이 하는 일

Home Assistant 서버의 지리적 경도를 지정합니다. 일출/일몰 시간 계산, 날씨 정보 등에 사용됩니다.

## 기본값

- **기본값**: 없음 (설정 필요)
- **형식**: 소수점 숫자 (-180 ~ 180)

## 설정 예시

### 서울
```
126.9780
```

### 뉴욕
```
-74.0060
```

## 알아야 할 것들

### 위도와 경도

위도와 경도는 함께 사용됩니다:
- **위도**: 남북 위치 (-90 ~ 90)
- **경도**: 동서 위치 (-180 ~ 180)

### 사용 용도

위도/경도는 다음에 사용됩니다:
- 일출/일몰 시간 계산
- 날씨 정보
- 위치 기반 자동화

## 자주 발생하는 오류

### 일출/일몰 시간이 잘못됨
**원인**: 위도/경도 설정 오류

**해결 방법**:
1. 올바른 위도/경도 설정
2. 위치 확인
3. Home Assistant 재시작
