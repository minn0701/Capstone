# ENSM SSH 비밀번호

## 개요

SSH 접속에 사용할 비밀번호를 지정하는 설정입니다. 원격 서버에 SSH로 접속할 때 사용됩니다.

## 설정 방법

SSH 접속에 사용할 비밀번호를 입력합니다. 비밀번호 필드이므로 입력 내용이 숨겨집니다.

## 주요 특징

- **평문 저장**: 비밀번호가 평문으로 저장되므로 보안에 주의해야 합니다
- **SSH 키 권장**: 보안을 위해 SSH 키 기반 인증을 사용하는 것을 강력히 권장합니다
- **암호화**: 가능하면 비밀번호 대신 SSH 키를 사용하세요

## 보안 주의사항

⚠️ **중요**: 비밀번호는 평문으로 저장되므로 다음 사항에 주의하세요:

1. **최소 권한**: 필요한 최소 권한만 가진 사용자의 비밀번호를 사용
2. **강력한 비밀번호**: 복잡하고 긴 비밀번호 사용
3. **SSH 키 사용**: 가능하면 SSH 키 기반 인증 사용
4. **정기 변경**: 비밀번호를 정기적으로 변경

## SSH 키 기반 인증 권장

SSH 키를 사용하면 비밀번호 없이 안전하게 접속할 수 있습니다:

1. SSH 키 생성
2. 원격 서버에 공개키 복사
3. 비밀번호 대신 SSH 키 사용

## 대안

비밀번호 대신 다음 방법을 사용할 수 있습니다:

- **SSH 키**: 공개키/개인키 쌍 사용
- **SSH 에이전트**: SSH 에이전트를 통한 키 관리
- **인증서**: SSH 인증서 사용
