# 데이터 저장 경로 (Data Root)

## 이 옵션이 하는 일

Docker가 이미지, 컨테이너, 볼륨, 네트워크 등 모든 데이터를 저장할 디렉토리 경로를 지정합니다. 기본적으로 `/var/lib/docker`에 저장됩니다.

## 기본값

- **기본값**: `/var/lib/docker`
- **일반적인 경로**: `/var/lib/docker`

## 경로 설정 예시

### 표준 경로
```
/var/lib/docker              → 기본 경로 (권장)
```

### 대용량 저장소
```
/mnt/docker                  → 별도 디스크
/data/docker                  → 데이터 디스크
/opt/docker                   → 대체 경로
```

### 사용자 정의 경로
```
/home/docker/data             → 사용자 홈 디렉토리
/storage/docker               → 스토리지 서버
```

## 알아야 할 것들

### 저장되는 데이터

이 경로에 다음이 저장됩니다:
- **이미지**: Docker 이미지 파일
- **컨테이너**: 컨테이너 파일 시스템
- **볼륨**: 영구 데이터 볼륨
- **네트워크**: 네트워크 설정
- **빌드 캐시**: 빌드 중간 결과

### 디스크 공간

Docker는 많은 디스크 공간을 사용할 수 있습니다:
- **이미지**: 수백 MB ~ 수 GB
- **컨테이너**: 이미지 크기 + 데이터
- **볼륨**: 사용자 데이터

충분한 디스크 공간이 필요합니다.

### 경로 변경 시

경로를 변경하면:
- 기존 데이터는 이동해야 함
- Docker 서비스 중지 필요
- 데이터 백업 권장

## 자주 발생하는 오류

### "No space left on device" 오류
**원인**: 디스크 공간 부족

**해결 방법**:
1. 사용하지 않는 이미지/컨테이너 삭제:
   ```bash
   docker system prune -a
   ```
2. 더 큰 디스크로 이동
3. 디스크 할당량 확인

### 경로 변경 후 데이터가 사라짐
**원인**: 기존 데이터를 이동하지 않음

**해결 방법**:
1. Docker 서비스 중지
2. 기존 데이터를 새 경로로 이동
3. Docker 서비스 시작

### 권한 오류
**원인**: Docker 사용자가 디렉토리에 접근 불가

**해결 방법**:
```bash
# 디렉토리 생성 및 권한 설정
sudo mkdir -p /var/lib/docker
sudo chown root:root /var/lib/docker
sudo chmod 700 /var/lib/docker
```
