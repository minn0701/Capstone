# 최대 동시 연결 수 (Max Clients)

## 이 옵션이 하는 일

FTP 서버에 동시에 접속할 수 있는 최대 클라이언트 수를 지정합니다. 서버 리소스를 보호하고 과부하를 방지하는 데 사용됩니다.

## 기본값

- **기본값**: 0 (제한 없음)
- **권장 설정**: 서버 성능에 따라 다름

## 설정 예시

### 제한 없음
```
0
```
→ 무제한 동시 연결 (기본값)

### 소규모 서버
```
10
20
```
→ 10-20개 동시 연결

### 중규모 서버
```
50
100
```
→ 50-100개 동시 연결

### 대규모 서버
```
200
500
```
→ 200-500개 동시 연결

## 알아야 할 것들

### 서버 리소스 고려

동시 연결 수는 서버 성능에 따라 결정됩니다:
- **CPU**: 각 연결이 CPU 사용
- **메모리**: 각 연결이 메모리 사용
- **네트워크 대역폭**: 데이터 전송 속도

### 권장 설정

- **소규모 서버**: 10-20
- **중규모 서버**: 50-100
- **대규모 서버**: 200-500
- **제한 없음**: 0 (주의 필요)

### max_per_ip와의 관계

- **max_clients**: 전체 동시 연결 수
- **max_per_ip**: IP당 최대 연결 수

둘 다 설정하면 더 세밀한 제어 가능.

## 자주 발생하는 오류

### "Too many connections" 오류
**원인**: 최대 연결 수에 도달

**해결 방법**:
1. `max_clients` 값 증가
2. 기존 연결 종료 대기
3. 서버 성능 향상

### 서버가 느려짐
**원인**: 너무 많은 동시 연결

**해결 방법**:
1. `max_clients` 값 감소
2. 서버 리소스 확인
3. 불필요한 연결 종료

### 연결이 거부됨
**확인 사항**:
1. `max_clients` 설정 확인
2. 현재 연결 수 확인
3. 서버 로그 확인
