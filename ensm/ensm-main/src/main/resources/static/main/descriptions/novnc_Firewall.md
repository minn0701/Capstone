# 방화벽 포트 허용 (Firewall)

## 이 옵션이 하는 일

noVNC가 사용하는 포트(웹 포트, WebSocket 포트)를 시스템 방화벽에서 자동으로 열어주는 기능입니다.

## 왜 필요한가요?

noVNC는 네트워크의 다른 컴퓨터에서 접근할 수 있어야 합니다. 방화벽이 포트를 차단하면 웹 브라우저에서 VNC에 접속할 수 없습니다.

## 동작 방식

### 활성화 시 (ON)
- 웹 포트(기본: 6080) 허용
- WebSocket 포트(기본: 6081) 허용
- 외부에서 noVNC 접속 가능

### 비활성화 시 (OFF)
- 방화벽 규칙 추가 안 됨
- 로컬에서만 접속 가능
- 외부 접근 불가

## 알아야 할 것들

### 두 포트 모두 필요

noVNC는 두 포트를 모두 사용합니다:
- **웹 포트**: HTTP 웹 인터페이스
- **WebSocket 포트**: VNC 데이터 전송

## 자주 발생하는 오류

### 외부에서 접속이 안 됨
**확인 사항**:
1. 방화벽 설정 확인
2. 두 포트 모두 열려있는지 확인
3. 클라우드 환경: 보안 그룹 확인
