# IP당 최대 연결 수 (Max Per IP)

## 이 옵션이 하는 일

하나의 IP 주소에서 동시에 접속할 수 있는 최대 연결 수를 지정합니다. 단일 클라이언트가 너무 많은 연결을 사용하는 것을 방지합니다.

## 기본값

- **기본값**: 0 (제한 없음)
- **권장 설정**: 1-5

## 설정 예시

### 제한 없음
```
0
```
→ IP당 무제한 연결 (기본값)

### 일반적인 제한
```
1
2
```
→ IP당 1-2개 연결 (권장)

### 다중 연결 허용
```
5
10
```
→ IP당 5-10개 연결

## 알아야 할 것들

### 왜 필요한가요?

단일 클라이언트가 너무 많은 연결을 사용하면:
- 서버 리소스 독점
- 다른 사용자 접근 차단
- 서버 과부하

### max_clients와의 관계

- **max_clients**: 전체 동시 연결 수
- **max_per_ip**: IP당 최대 연결 수

예시:
- `max_clients=100`, `max_per_ip=5`
- 최대 100개 연결, IP당 최대 5개

### 권장 설정

- **일반적인 사용**: 1-2
- **다중 파일 전송**: 3-5
- **제한 없음**: 0 (주의 필요)

## 자주 발생하는 오류

### "Too many connections from this IP" 오류
**원인**: IP당 최대 연결 수에 도달

**해결 방법**:
1. `max_per_ip` 값 증가
2. 기존 연결 종료
3. 또는 다중 연결 사용 중지

### 다중 파일 전송이 안 됨
**원인**: `max_per_ip=1`로 설정됨

**해결 방법**:
1. `max_per_ip` 값을 3-5로 증가
2. 또는 순차적으로 전송

### 특정 IP가 모든 연결을 차지함
**원인**: `max_per_ip` 제한이 없음

**해결 방법**:
1. `max_per_ip` 설정 (예: 5)
2. 공정한 리소스 분배
