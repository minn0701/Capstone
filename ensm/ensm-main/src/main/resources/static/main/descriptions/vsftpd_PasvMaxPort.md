# 수동 모드 최대 포트 (PASV Max Port)

## 이 옵션이 하는 일

PASV(수동) 모드에서 사용할 포트 범위의 끝 포트를 지정합니다. `pasv_min_port`와 함께 포트 범위를 정의합니다.

## 기본값

- **일반적인 설정**: 21110
- **pasv_min_port와의 차이**: 사용 가능한 포트 개수 결정

## 설정 예시

### 작은 범위
```
최소: 21100
최대: 21110
```
→ 10개 포트 사용

### 큰 범위
```
최소: 50000
최대: 51000
```
→ 1000개 포트 사용

## 알아야 할 것들

### 포트 개수 계산

사용 가능한 포트 개수 = `pasv_max_port - pasv_min_port + 1`

예시:
- 21100-21110: 11개 포트
- 50000-51000: 1001개 포트

### 동시 연결 수

각 파일 전송은 하나의 포트를 사용합니다:
- 10개 포트: 최대 10개 동시 전송
- 1000개 포트: 최대 1000개 동시 전송

### 방화벽 설정

최소 포트부터 최대 포트까지 모두 열어야 합니다:

```bash
# ufw
sudo ufw allow 21100:21110/tcp

# firewalld
sudo firewall-cmd --permanent --add-port=21100-21110/tcp
```

## 자주 발생하는 오류

### 포트 범위가 너무 작음
**증상**: 많은 사용자가 동시 접속 시 "425 Can't open data connection" 오류

**해결 방법**:
- 포트 범위를 늘림
- 예: 21100-21110 → 21100-21200

### 최대 포트가 최소 포트보다 작음
**원인**: 설정 오류

**해결 방법**:
- `pasv_max_port`가 `pasv_min_port`보다 크거나 같아야 함
- 올바른 값으로 수정
