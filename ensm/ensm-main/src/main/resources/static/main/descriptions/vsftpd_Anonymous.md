# 익명 사용자 접근 허용 (Anonymous Enable)

## 이 옵션이 하는 일

익명(anonymous) 사용자가 비밀번호 없이 FTP 서버에 접속할 수 있게 할지 결정합니다. 공개 파일 다운로드를 제공할 때 사용합니다.

## 동작 방식

### 활성화 시 (ON)
- `anonymous` 또는 `ftp` 사용자명으로 로그인 가능
- 비밀번호는 이메일 주소 또는 아무 값이나 입력 가능
- 익명 사용자 전용 디렉토리에 접근

### 비활성화 시 (OFF, 권장)
- 익명 접속 불가
- 로컬 사용자만 접근 가능
- 보안상 안전

## 사용 시나리오

### 활성화가 필요한 경우
- **공개 파일 다운로드**: 소프트웨어 배포, 문서 공유
- **미러 사이트**: Linux 배포판, 오픈소스 프로젝트
- **공개 자료실**: 누구나 다운로드 가능한 파일

### 비활성화가 권장되는 경우 (대부분)
- **일반적인 FTP 서버**: 사용자 인증 필요
- **보안**: 불필요한 접근 차단
- **프로덕션 환경**: 대부분의 경우

## 알아야 할 것들

### 익명 사용자 디렉토리

익명 사용자는 특정 디렉토리에만 접근 가능:
- 일반적으로 `/var/ftp` 또는 `/srv/ftp`
- 읽기 전용 권한 권장
- 쓰기 권한은 보안상 위험

### 보안 고려사항

**위험 요소**:
- 누구나 접근 가능
- 파일 업로드 시 악성 파일 위험
- 디스크 공간 남용 가능

**안전한 설정**:
- 읽기 전용 권한
- 업로드 디렉토리 분리 및 검사
- 정기적인 모니터링

### 익명 디렉토리 설정

```bash
# 익명 FTP 디렉토리 생성
sudo mkdir -p /var/ftp/pub

# 권한 설정 (읽기 전용)
sudo chown ftp:ftp /var/ftp
sudo chmod 755 /var/ftp
sudo chmod 755 /var/ftp/pub
```

## 자주 발생하는 오류

### 익명 로그인이 안 됨
**확인 사항**:
1. `anonymous_enable` 활성화 확인
2. 익명 디렉토리가 존재하는지 확인
3. 디렉토리 권한 확인

### 보안 스캔에서 경고
**원인**: 익명 접근 활성화로 인한 보안 위험

**해결 방법**:
1. 불필요한 경우 비활성화
2. 읽기 전용으로 제한
3. 업로드 비활성화
4. 정기적인 모니터링

### 디스크 공간이 가득 참
**원인**: 익명 사용자가 대용량 파일 업로드

**해결 방법**:
1. 업로드 비활성화
2. 디스크 할당량 설정
3. 정기적인 파일 정리
