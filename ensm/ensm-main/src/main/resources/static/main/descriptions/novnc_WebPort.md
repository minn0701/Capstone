# 웹 인터페이스 포트 (Web Port)

## 이 옵션이 하는 일

noVNC 웹 인터페이스가 클라이언트의 요청을 받을 포트 번호를 지정합니다. 브라우저에서 이 포트로 접속하여 VNC 서버에 연결할 수 있습니다.

## 기본값

- **기본값**: 6080
- **표준 포트**: 6080 (noVNC 기본 포트)

## 포트 설정

### 표준 포트 (6080)
```
6080        → noVNC 기본 포트 (권장)
```
→ 대부분의 경우 이 포트 사용

### 대체 포트
```
6081        → 다른 서비스와 충돌 시
8080        → 개발/테스트용
```
→ 특수한 경우에만 사용

## 알아야 할 것들

### WebSocket 포트와의 관계

noVNC는 두 개의 포트를 사용합니다:
- **웹 포트 (6080)**: HTTP 웹 인터페이스
- **WebSocket 포트 (6081)**: VNC 데이터 전송

두 포트 모두 필요합니다.

### 접속 방법

브라우저에서 접속:
- `http://서버주소:6080/vnc.html`
- 또는 `http://서버주소:6080`

### VNC 서버 필요

noVNC는 VNC 서버에 연결하는 웹 클라이언트입니다:
- VNC 서버가 먼저 실행되어야 함
- VNC 서버 포트(기본: 5900) 확인
- VNC 서버 비밀번호 설정

## 자주 발생하는 오류

### "Connection refused" 오류
**원인**: 
- 포트가 방화벽에서 차단됨
- noVNC 서비스가 실행되지 않음

**해결 방법**:
1. noVNC 서비스 상태 확인
2. 방화벽에서 포트 열기
3. 서비스 재시작

### VNC 연결이 안 됨
**확인 사항**:
1. VNC 서버가 실행 중인지 확인
2. VNC 호스트/포트 설정 확인
3. VNC 서버 비밀번호 확인
4. WebSocket 포트 설정 확인

### WebSocket 연결 오류
**원인**: WebSocket 포트가 차단되거나 잘못 설정됨

**해결 방법**:
1. WebSocket 포트 설정 확인
2. 방화벽에서 WebSocket 포트 열기
3. 프록시 설정 확인 (있는 경우)
