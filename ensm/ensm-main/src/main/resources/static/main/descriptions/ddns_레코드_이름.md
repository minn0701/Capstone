# DDNS 레코드 이름

## 개요

업데이트할 DNS 레코드의 이름을 지정하는 설정입니다. IP 주소가 변경될 때 이 레코드가 자동으로 업데이트됩니다.

## 설정 방법

DNS 레코드 이름을 입력합니다:

```
ddns.example.com
```

또는 루트 도메인:

```
@
```

## 주요 특징

- **레코드 이름**: 업데이트할 DNS 레코드의 이름
- **루트 도메인**: `@`를 사용하면 루트 도메인을 의미합니다
- **서브도메인**: 서브도메인을 지정할 수 있습니다

## 일반적인 사용 예시

```
# 서브도메인
ddns.example.com
home.example.com
server.example.com

# 루트 도메인
@
example.com
```

## 레코드 타입

DDNS는 A 레코드(IPv4) 또는 AAAA 레코드(IPv6)를 업데이트합니다:

- **A 레코드**: IPv4 주소
- **AAAA 레코드**: IPv6 주소

## 주의사항

- **레코드 존재**: Cloudflare에 해당 레코드가 존재해야 합니다
- **레코드 타입**: A 또는 AAAA 레코드여야 합니다
- **프록시 상태**: Cloudflare 프록시 상태는 변경되지 않습니다

## 루트 도메인 사용

루트 도메인(`@`)을 사용하면 `example.com` 자체의 IP 주소를 업데이트합니다:

```
@ = example.com
```

## 서브도메인 사용

서브도메인을 사용하면 해당 서브도메인의 IP 주소를 업데이트합니다:

```
ddns.example.com = ddns.example.com의 IP 주소
```
