# Lockd 포트 (Lockd Port)

## 이 옵션이 하는 일

NFS Lockd(Lock Manager) 데몬이 사용할 포트 번호를 지정합니다. Lockd는 파일 잠금을 관리합니다.

## 기본값

- **기본값**: 32768
- **일반적인 포트**: 32768

## 포트 설정

### 표준 포트 (32768)
```
32768        → Lockd 기본 포트 (권장)
```
→ 대부분의 경우 이 포트 사용

### 대체 포트
```
32769        → 다른 서비스와 충돌 시
```
→ 특수한 경우에만 사용

## 알아야 할 것들

### Lockd의 역할

Lockd는 다음을 처리합니다:
- 파일 잠금 요청 처리
- 잠금 상태 관리
- 잠금 해제 처리

### Statd와의 관계

Lockd와 Statd는 함께 작동합니다:
- **Statd**: 상태 모니터링
- **Lockd**: 잠금 관리

### 선택사항

Lockd는 필수는 아닙니다:
- 파일 잠금을 사용하지 않으면 불필요
- 하지만 권장됨 (안정성)

### 방화벽 설정

Lockd 포트도 방화벽에서 열어야 합니다:
- TCP/UDP 32768: Lockd

## 자주 발생하는 오류

### 파일 잠금이 작동하지 않음
**원인**: Lockd가 실행되지 않거나 포트가 차단됨

**해결 방법**:
1. Lockd 서비스 확인
2. 방화벽에서 포트 열기
3. NFS 서비스 재시작
