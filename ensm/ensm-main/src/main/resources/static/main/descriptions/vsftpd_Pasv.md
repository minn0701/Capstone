# 수동 모드 활성화 (PASV Enable)

## 이 옵션이 하는 일

FTP의 수동 모드(Passive Mode, PASV)를 활성화합니다. 방화벽 환경에서 FTP 연결이 제대로 작동하도록 하는 중요한 옵션입니다.

## 동작 방식

### 활성화 시 (ON, 권장)
- 클라이언트가 서버의 데이터 포트에 연결
- 방화벽 환경에서 잘 작동
- 대부분의 경우 권장

### 비활성화 시 (OFF)
- Active 모드만 사용
- 클라이언트가 포트를 열고 서버가 연결
- 방화벽 환경에서 문제 발생 가능

## Active vs Passive 모드

### Active 모드 (기본)
- 서버가 클라이언트의 포트에 연결
- 클라이언트 방화벽에서 포트를 열어야 함
- 문제 발생 가능

### Passive 모드 (PASV, 권장)
- 클라이언트가 서버의 포트에 연결
- 서버 방화벽만 열면 됨
- 대부분의 환경에서 잘 작동

## 알아야 할 것들

### PASV 포트 범위

PASV 모드 사용 시 포트 범위를 지정해야 합니다:
- **최소 포트**: `pasv_min_port` (예: 21100)
- **최대 포트**: `pasv_max_port` (예: 21110)
- 이 범위를 방화벽에서 열어야 함

### 방화벽 설정

PASV 모드 사용 시:
1. 제어 포트(21) 열기
2. PASV 포트 범위 열기 (예: 21100-21110)
3. 두 포트 모두 TCP 프로토콜

### 포트 범위 크기

- **작은 범위**: 10-20개 포트 (소규모)
- **큰 범위**: 100-1000개 포트 (대규모, 많은 동시 연결)

## 자주 발생하는 오류

### "425 Can't open data connection" 오류
**원인**: PASV 포트 범위가 방화벽에서 열리지 않음

**해결 방법**:
1. PASV 포트 범위 확인
2. 방화벽에서 해당 범위 열기
3. `pasv_address` 설정 확인 (NAT 환경)

### 방화벽 환경에서 연결이 끊김
**원인**: Active 모드 사용 또는 PASV 포트 미설정

**해결 방법**:
1. `pasv_enable` 활성화
2. PASV 포트 범위 설정
3. 방화벽 규칙 확인

### NAT 환경에서 PASV가 안 됨
**원인**: 서버의 공용 IP 주소가 올바르게 설정되지 않음

**해결 방법**:
- `pasv_address` 옵션에 공용 IP 주소 설정
- 또는 NAT 게이트웨이에서 포트 포워딩
