# 수동 모드 최소 포트 (PASV Min Port)

## 이 옵션이 하는 일

PASV(수동) 모드에서 사용할 포트 범위의 시작 포트를 지정합니다. 파일 전송을 위한 데이터 연결에 사용됩니다.

## 기본값

- **일반적인 설정**: 21100
- **권장 범위**: 10000-65535

## 설정 예시

### 작은 범위
```
21100    → 최소 포트
21110    → 최대 포트
```
→ 10개 포트 사용 (소규모)

### 큰 범위
```
50000    → 최소 포트
51000    → 최대 포트
```
→ 1000개 포트 사용 (대규모)

## 알아야 할 것들

### 포트 범위 크기

**소규모 서버**:
- 10-20개 포트면 충분
- 예: 21100-21110

**대규모 서버**:
- 100-1000개 포트 필요
- 예: 50000-51000

### 방화벽 설정

이 포트 범위를 방화벽에서 열어야 합니다:

```bash
# ufw
sudo ufw allow 21100:21110/tcp

# firewalld
sudo firewall-cmd --permanent --add-port=21100-21110/tcp
```

### pasv_max_port와의 관계

- `pasv_min_port`: 범위 시작
- `pasv_max_port`: 범위 끝
- 두 값 사이의 모든 포트가 사용됨

## 자주 발생하는 오류

### 포트 범위가 너무 작음
**증상**: 많은 사용자가 동시 접속 시 포트 부족

**해결 방법**:
- 포트 범위를 늘림 (예: 21100-21200)
- 또는 더 큰 범위 사용 (예: 50000-51000)

### 방화벽에서 포트가 열리지 않음
**확인 사항**:
1. 포트 범위가 올바른지 확인
2. 방화벽 규칙 확인
3. 포트 충돌 확인
