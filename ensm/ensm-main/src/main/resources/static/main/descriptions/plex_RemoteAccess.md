# 원격 접근 허용 (Enable Remote Access)

## 이 옵션이 하는 일

인터넷을 통해 Plex 미디어 서버에 접속할 수 있게 할지 결정합니다. 활성화하면 집 밖에서도 Plex 서버에 접속하여 미디어를 시청할 수 있습니다.

## 동작 방식

### 활성화 시 (ON)
- 인터넷을 통한 접속 허용
- Plex 계정으로 자동 연결
- 원격 클라이언트에서 접속 가능
- **보안**: Plex 인증 필요

### 비활성화 시 (OFF)
- 로컬 네트워크에서만 접속 가능
- 외부 접속 차단
- 보안 강화

## 사용 시나리오

### 활성화가 유용한 경우
- **외부 시청**: 집 밖에서 미디어 시청
- **여러 장소**: 여러 위치에서 접속
- **공유**: 가족/친구와 미디어 공유

### 비활성화가 권장되는 경우
- **보안**: 외부 접속 불필요
- **로컬만 사용**: 집에서만 사용
- **대역폭 절약**: 외부 접속으로 인한 트래픽 방지

## 알아야 할 것들

### Plex 계정 필요

원격 접근을 사용하려면:
- Plex 계정 필요 (무료)
- 서버와 클라이언트 모두 같은 계정으로 로그인
- 자동 인증 및 연결

### 네트워크 설정

원격 접근 활성화 시:
- 방화벽에서 포트 열기 (자동 처리 가능)
- 라우터 UPnP 지원 시 자동 포트 포워딩
- 또는 수동 포트 포워딩 설정

### 보안 고려사항

**Plex의 보안**:
- Plex 계정 인증 필요
- 사용자별 접근 권한 설정 가능
- 암호화 연결 지원

**주의사항**:
- 강력한 Plex 계정 비밀번호 사용
- 불필요한 사용자 공유 제한

## 자주 발생하는 오류

### 원격 접속이 안 됨
**확인 사항**:
1. `enableRemoteAccess` 활성화 확인
2. Plex 계정 연결 확인
3. 방화벽/라우터 설정 확인
4. 인터넷 연결 확인

### "Unable to reach server" 오류
**원인**: 
- 네트워크 문제
- 방화벽 차단
- 포트 포워딩 미설정

**해결 방법**:
1. 방화벽 설정 확인
2. 라우터 포트 포워딩 설정
3. UPnP 활성화 (라우터에서)

### 연결이 느림
**원인**: 
- 인터넷 업로드 속도 부족
- 서버 하드웨어 성능
- 네트워크 품질

**해결 방법**:
1. 인터넷 속도 확인
2. 트랜스코딩 설정 조정
3. 원격 품질 설정 낮추기
