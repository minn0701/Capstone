# DDNS TTL (초)

## 개요

DNS 레코드의 TTL(Time To Live) 값을 초 단위로 지정하는 설정입니다. DNS 클라이언트가 레코드를 캐시하는 시간을 의미합니다.

## 설정 방법

TTL 값을 초 단위로 입력합니다:

```
120
```

## 주요 특징

- **단위**: 초(seconds) 단위
- **최소값**: 60초 이상이어야 합니다
- **캐시 시간**: DNS 클라이언트가 레코드를 캐시하는 시간

## 일반적인 사용 예시

```
# 1분
60

# 2분
120

# 5분
300

# 1시간
3600
```

## TTL 선택 가이드

- **짧은 TTL (60-300초)**: IP가 자주 변경되는 경우, 빠른 업데이트 반영
- **중간 TTL (300-1800초)**: 일반적인 DDNS 사용
- **긴 TTL (1800초 이상)**: IP가 안정적인 경우, DNS 쿼리 감소

## 주의사항

- **최소값**: Cloudflare는 최소 60초를 요구합니다
- **변경 반영**: 짧은 TTL은 빠른 변경 반영, 긴 TTL은 느린 변경 반영
- **DNS 쿼리**: 짧은 TTL은 DNS 쿼리 증가, 긴 TTL은 DNS 쿼리 감소

## 권장 설정

일반적인 DDNS 사용 시 권장 설정:

- **동적 IP**: 120-300초 (2-5분)
- **안정적 IP**: 1800-3600초 (30분-1시간)

## Cloudflare 제한

Cloudflare는 다음 TTL 값을 사용합니다:

- **자동**: Cloudflare가 자동으로 TTL 관리
- **수동**: 사용자가 지정한 TTL 값 사용 (최소 60초)
