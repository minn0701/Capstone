# ENSM SSH를 통한 원격 실행 사용

## 개요

원격 서버에서 Apache 설정을 변경할 때 SSH를 통해 실행할지 여부를 지정하는 설정입니다. 로컬 서버가 아닌 원격 서버의 Apache를 관리할 때 사용합니다.

## 설정 방법

체크박스를 통해 활성화/비활성화합니다:

- ✅ 체크: SSH를 통한 원격 실행 활성화
- ❌ 체크 해제: 로컬 실행 (기본값)

## 주요 특징

- **원격 관리**: 원격 서버의 Apache를 관리할 수 있습니다
- **SSH 연결**: SSH를 통해 원격 서버에 접속하여 스크립트를 실행합니다
- **보안**: SSH 인증 정보가 필요합니다

## 활성화 시 추가 설정

SSH를 통한 원격 실행을 활성화하면 다음 설정이 필요합니다:

- **SSH 호스트**: 원격 서버의 IP 주소 또는 호스트명
- **SSH 사용자**: SSH 접속에 사용할 사용자명
- **SSH 비밀번호**: SSH 접속에 사용할 비밀번호

## 주의사항

- **보안**: SSH 비밀번호가 평문으로 저장되므로 보안에 주의해야 합니다
- **SSH 키**: 가능하면 SSH 키 기반 인증을 사용하는 것을 권장합니다
- **네트워크**: 원격 서버와의 네트워크 연결이 필요합니다

## 권장 설정

보안을 위해 SSH 키 기반 인증을 사용하는 것을 권장합니다:

1. SSH 키 생성
2. 원격 서버에 공개키 복사
3. 비밀번호 대신 SSH 키 사용
