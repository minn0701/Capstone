# VNC 서버 호스트 (VNC Host)

## 이 옵션이 하는 일

noVNC가 연결할 VNC 서버의 호스트 주소를 지정합니다. noVNC는 이 주소의 VNC 서버에 연결하여 화면을 웹 브라우저에 표시합니다.

## 기본값

- **기본값**: `localhost`
- **일반적인 설정**: `localhost` 또는 `127.0.0.1`

## 설정 예시

### 로컬 VNC 서버
```
localhost
127.0.0.1
```
→ 같은 컴퓨터의 VNC 서버에 연결

### 원격 VNC 서버
```
192.168.1.100
10.0.0.50
vnc.example.com
```
→ 네트워크의 다른 컴퓨터에 연결

## 알아야 할 것들

### VNC 서버 필요

noVNC는 VNC 서버에 연결하는 클라이언트입니다:
- VNC 서버가 먼저 설치 및 실행되어야 함
- VNC 서버 포트 확인 (기본: 5900)
- VNC 서버 비밀번호 설정

### VNC 서버 설치

일반적인 VNC 서버:
- **TigerVNC**: Linux에서 널리 사용
- **RealVNC**: 상용 및 무료 버전
- **TightVNC**: 가벼운 VNC 서버

### 포트 번호

VNC 서버는 포트 번호를 사용합니다:
- **5900**: 디스플레이 :0
- **5901**: 디스플레이 :1
- **5902**: 디스플레이 :2

## 자주 발생하는 오류

### "Connection refused" 오류
**원인**: 
- VNC 서버가 실행되지 않음
- 호스트 주소가 잘못됨
- VNC 서버 포트가 다름

**해결 방법**:
1. VNC 서버 상태 확인
2. 호스트 주소 확인
3. VNC 서버 포트 확인

### VNC 서버를 찾을 수 없음
**원인**: 
- 네트워크 연결 문제
- 호스트 주소 오타
- 방화벽 차단

**해결 방법**:
1. 네트워크 연결 확인
2. 호스트 주소 재확인
3. 방화벽 설정 확인
4. `ping` 명령어로 연결 테스트

### 비밀번호 오류
**원인**: VNC 서버 비밀번호가 다름

**해결 방법**:
1. VNC 서버 비밀번호 확인
2. noVNC 연결 시 올바른 비밀번호 입력
