# DNS 서버 (DNS)

## 이 옵션이 하는 일

Docker 컨테이너에서 사용할 DNS 서버 주소를 지정합니다. 컨테이너가 도메인 이름을 IP 주소로 변환할 때 이 DNS 서버를 사용합니다.

## 기본값

- **기본값**: 호스트 시스템의 DNS 설정 사용
- **일반적인 설정**: `8.8.8.8` (Google DNS)

## 설정 예시

### Google DNS
```
8.8.8.8
```
→ Google의 공용 DNS 서버

### 여러 DNS 서버
```
8.8.8.8, 8.8.4.4
1.1.1.1, 1.0.0.1
```
→ 여러 DNS 서버 지정 (쉼표로 구분)

### Cloudflare DNS
```
1.1.1.1
```
→ Cloudflare의 공용 DNS 서버 (빠름)

### ISP DNS
```
203.248.252.2
```
→ 인터넷 제공업체의 DNS 서버

## 알아야 할 것들

### DNS 서버 선택

**Google DNS (8.8.8.8)**:
- 빠르고 안정적
- 널리 사용됨

**Cloudflare DNS (1.1.1.1)**:
- 매우 빠름
- 프라이버시 보호

**ISP DNS**:
- 지역에 따라 빠를 수 있음
- 로그 수집 가능

### 여러 DNS 서버

여러 DNS를 지정하면:
- 첫 번째 서버 실패 시 다음 서버 사용
- 로드 밸런싱
- 안정성 향상

### 컨테이너별 DNS

각 컨테이너는 이 DNS 설정을 사용합니다:
- 네트워크 요청 시 DNS 조회
- 도메인 이름 해석
- 외부 서비스 연결

## 자주 발생하는 오류

### 컨테이너에서 도메인을 찾을 수 없음
**원인**: 
- DNS 서버가 응답하지 않음
- DNS 설정이 잘못됨

**해결 방법**:
1. DNS 서버 주소 확인
2. 네트워크 연결 확인
3. 다른 DNS 서버 사용

### DNS 조회가 느림
**원인**: DNS 서버가 느리거나 멀리 있음

**해결 방법**:
1. 빠른 DNS 서버 사용 (예: 1.1.1.1)
2. 여러 DNS 서버 지정
3. 지역에 가까운 DNS 사용
