# 자격 증명 도우미 (Credential Helper)

## 이 옵션이 하는 일

Git이 사용자 이름과 비밀번호를 저장하고 관리하는 방식을 지정합니다. 매번 입력하지 않아도 되도록 자격 증명을 저장합니다.

## 선택지 설명

### store (기본)
- **의미**: 평문으로 파일에 저장
- **장점**: 간단하고 사용하기 쉬움
- **단점**: 보안 위험 (평문 저장)
- **사용 시기**: 로컬 개발 환경

### cache
- **의미**: 메모리에 일시적으로 저장
- **장점**: 세션 동안만 유지, 비교적 안전
- **단점**: 재부팅 시 사라짐
- **사용 시기**: 임시 사용

### manager
- **의미**: 시스템 자격 증명 관리자 사용 (Windows)
- **장점**: 안전한 저장
- **단점**: Windows에서만 사용 가능
- **사용 시기**: Windows 환경

### osxkeychain
- **의미**: macOS 키체인 사용
- **장점**: 안전한 저장
- **단점**: macOS에서만 사용 가능
- **사용 시기**: macOS 환경

## 알아야 할 것들

### 저장 위치

**store 사용 시**:
- 저장 위치: `~/.git-credentials`
- 형식: `https://username:password@host`
- **주의**: 평문으로 저장됨

### 보안 고려사항

**store (평문 저장)**:
- ⚠️ 보안 위험
- 파일 권한 설정 필요: `chmod 600 ~/.git-credentials`
- 로컬 개발 환경에서만 사용 권장

**cache (메모리)**:
- ✅ 비교적 안전
- 세션 종료 시 자동 삭제
- 임시 사용에 적합

### SSH 키 사용

비밀번호 대신 SSH 키 사용 권장:
- 더 안전
- 비밀번호 입력 불필요
- 공개/개인 키 쌍 사용

## 자주 발생하는 오류

### 자격 증명이 저장되지 않음
**원인**: 
- `credential.helper` 설정 오류
- 파일 권한 문제

**해결 방법**:
1. 설정 확인: `git config credential.helper`
2. 파일 권한 확인: `chmod 600 ~/.git-credentials`
3. 설정 재적용

### 보안 스캔에서 경고
**원인**: `store` 사용으로 평문 저장

**해결 방법**:
1. SSH 키 사용 권장
2. 또는 `cache` 사용 (임시)
3. 파일 권한 강화: `chmod 600`

### 자격 증명이 만료됨
**원인**: 
- `cache` 사용 시 세션 종료
- 토큰 만료

**해결 방법**:
1. 자격 증명 다시 입력
2. 또는 SSH 키 사용
