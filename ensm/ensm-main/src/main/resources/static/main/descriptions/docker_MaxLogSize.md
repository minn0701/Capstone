# 최대 로그 크기 (Max Log Size)

## 이 옵션이 하는 일

컨테이너 로그 파일의 최대 크기를 지정합니다. 이 크기에 도달하면 로그 파일이 로테이션됩니다.

## 기본값

- **기본값**: `10m` (10MB)
- **일반적인 설정**: `10m` ~ `50m`

## 설정 예시

### 작은 크기
```
10m         → 10MB (기본값)
```
→ 작은 로그 파일, 빠른 로테이션

### 중간 크기
```
50m         → 50MB
100m        → 100MB
```
→ 균형잡힌 설정

### 큰 크기
```
500m        → 500MB
1g          → 1GB
```
→ 큰 로그 파일, 적은 로테이션

## 단위

- **b**: 바이트
- **k**: 킬로바이트
- **m**: 메가바이트
- **g**: 기가바이트

예시: `10m`, `50k`, `1g`

## 알아야 할 것들

### 로그 로테이션

크기에 도달하면:
- 현재 로그 파일 백업
- 새 로그 파일 생성
- `log_opt_max_file` 설정에 따라 오래된 파일 삭제

### 디스크 공간

로그 크기와 파일 개수를 고려:
- **크기**: `max_log_size` (예: 10m)
- **개수**: `log_opt_max_file` (예: 3)
- **최대 사용량**: 10m × 3 = 30MB (컨테이너당)

### 성능 영향

로그 크기가 클수록:
- 로그 파일이 커짐
- 로그 쓰기 성능 영향 가능
- 디스크 공간 사용 증가

## 자주 발생하는 오류

### 로그 파일이 너무 빠르게 로테이션됨
**원인**: `max_log_size`가 너무 작음

**해결 방법**:
1. 크기 값 증가 (예: 10m → 50m)
2. 로그 생성량 확인

### 디스크 공간 부족
**원인**: 로그 파일이 너무 많거나 큼

**해결 방법**:
1. `max_log_size` 감소
2. `log_opt_max_file` 감소
3. 오래된 로그 파일 삭제

### 로그가 잘림
**원인**: 로그 크기 제한으로 인한 로테이션

**설명**:
- 이것은 정상 동작입니다
- 오래된 로그는 백업 파일에 저장됨
- 필요시 크기 증가
