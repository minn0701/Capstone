# 쿼리 허용 범위 (AllowQuery)

## 이 옵션이 하는 일

어떤 클라이언트가 이 DNS 서버에 쿼리할 수 있는지 지정합니다. 보안을 위해 특정 IP 주소나 네트워크만 허용할 수 있습니다.

## 기본값

- **기본값**: `any` (모든 클라이언트 허용)

## 설정 예시

### 모든 클라이언트 허용
```
any
```
→ 누구나 DNS 쿼리 가능 (공용 DNS 서버)

### localhost만
```
localhost
127.0.0.1
```
→ 로컬 컴퓨터에서만 쿼리 가능

### 내부 네트워크만
```
192.168.0.0/16
10.0.0.0/8
```
→ 내부 네트워크 IP만 허용

### 특정 IP만
```
192.168.1.100
203.0.113.50
```
→ 지정한 IP 주소만 허용

### 여러 네트워크 조합
```
192.168.0.0/16; 10.0.0.0/8;
```
→ 여러 네트워크 허용 (세미콜론으로 구분)

## 알아야 할 것들

### CIDR 표기법

IP 주소 범위를 지정하는 방법:
- `192.168.1.0/24` → 192.168.1.0 ~ 192.168.1.255 (256개 IP)
- `10.0.0.0/8` → 10.0.0.0 ~ 10.255.255.255 (전체 10.x.x.x)
- `192.168.0.0/16` → 192.168.0.0 ~ 192.168.255.255

### 보안 고려사항

**공용 DNS 서버**:
- `any` 사용 (누구나 접근 가능해야 함)

**내부 DNS 서버**:
- 내부 네트워크만 허용 (예: `192.168.0.0/16`)
- 외부 접근 차단

**제한된 DNS 서버**:
- 특정 IP만 허용
- 최고 보안

### AllowQuery와 AllowTransfer의 차이

- **AllowQuery**: 일반 DNS 쿼리 허용
- **AllowTransfer**: Zone 전송(복제) 허용 (더 제한적)

## 자주 발생하는 오류

### "Query refused" 오류
**원인**: 클라이언트 IP가 허용 목록에 없음

**해결 방법**:
1. 클라이언트 IP 확인
2. 허용 목록에 추가
3. 또는 `any`로 변경 (공용 서버인 경우)

### 내부 네트워크에서 쿼리가 안 됨
**확인 사항**:
1. CIDR 표기법이 올바른지 확인
2. 클라이언트 IP가 허용 범위에 포함되는지 확인
3. 네트워크 마스크 확인

### 보안 스캔에서 경고
**원인**: `any`로 설정되어 외부 접근 가능

**해결 방법**:
1. 필요한 네트워크만 허용
2. 내부 네트워크 IP만 지정
3. 방화벽으로 추가 보호
