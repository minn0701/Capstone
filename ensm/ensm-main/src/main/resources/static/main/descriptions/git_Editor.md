# 기본 편집기 (Editor)

## 이 옵션이 하는 일

Git이 커밋 메시지를 작성하거나 병합 충돌을 해결할 때 사용할 텍스트 편집기를 지정합니다. 커밋 메시지를 입력할 때 이 편집기가 자동으로 열립니다.

## 선택지 설명

### vim
- **의미**: Vi Improved 텍스트 편집기
- **특징**: 터미널 기반, 강력한 기능
- **사용 시기**: Linux/Unix 환경, 고급 사용자
- **주의**: 초보자에게는 어려울 수 있음

### nano
- **의미**: 사용하기 쉬운 터미널 편집기
- **특징**: 간단하고 직관적
- **사용 시기**: **초보자 권장**
- **장점**: 화면 하단에 도움말 표시

### emacs
- **의미**: 강력한 텍스트 편집기
- **특징**: 확장 가능, 커스터마이징
- **사용 시기**: Emacs 사용자

### code (Visual Studio Code)
- **의미**: Visual Studio Code
- **특징**: GUI 편집기
- **사용 시기**: VS Code 사용자, GUI 선호
- **주의**: GUI 환경에서만 작동

## 알아야 할 것들

### 편집기 사용 시점

Git이 편집기를 사용하는 경우:
- `git commit` (메시지 없이 실행 시)
- `git rebase -i` (대화형 리베이스)
- 병합 충돌 해결
- `git tag` (태그 메시지)

### vim 사용법 (기본)

vim이 열리면:
1. `i` 키: 입력 모드로 전환
2. 메시지 작성
3. `Esc` 키: 명령 모드로 전환
4. `:wq` 입력 후 Enter: 저장하고 종료
5. `:q!` 입력 후 Enter: 저장하지 않고 종료

### nano 사용법 (기본)

nano가 열리면:
1. 바로 텍스트 입력 가능
2. `Ctrl + X`: 종료 (저장 여부 묻음)
3. `Ctrl + O`: 저장
4. 화면 하단에 단축키 표시

## 자주 발생하는 오류

### 편집기에서 나올 수 없음 (vim)
**해결 방법**:
1. `Esc` 키 누르기
2. `:q!` 입력 후 Enter (저장 안 함)
3. 또는 `:wq` 입력 후 Enter (저장하고 종료)

### 편집기가 열리지 않음
**원인**: 
- 편집기가 설치되지 않음
- 경로가 잘못됨

**해결 방법**:
1. 편집기 설치 확인: `which vim` 또는 `which nano`
2. 올바른 편집기 이름 확인
3. 전체 경로 사용: `/usr/bin/vim`

### GUI 편집기를 사용하고 싶음
**해결 방법**:
- `code` (VS Code) 사용
- 또는 `gedit`, `notepad++` 등
- 전체 경로 지정 가능
