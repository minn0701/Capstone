# 스토리지 드라이버 (Storage Driver)

## 이 옵션이 하는 일

Docker가 컨테이너 이미지와 레이어를 저장하고 관리하는 방식을 지정합니다. 각 드라이버는 다른 특성과 성능을 가집니다.

## 선택지 설명

### overlay2 (권장)
- **의미**: 최신 Overlay 파일시스템 버전 2
- **성능**: ✅ 매우 좋음
- **안정성**: ✅ 매우 안정적
- **사용 시기**: **대부분의 경우 권장**

### overlay
- **의미**: Overlay 파일시스템 (구버전)
- **성능**: ✅ 좋음
- **안정성**: ✅ 안정적
- **사용 시기**: overlay2를 사용할 수 없는 경우

### devicemapper
- **의미**: Device Mapper 기반
- **성능**: ⚠️ 보통
- **안정성**: ✅ 안정적
- **사용 시기**: 오래된 시스템, 특수한 경우

### btrfs
- **의미**: Btrfs 파일시스템 사용
- **성능**: ✅ 좋음
- **안정성**: ⚠️ 파일시스템 의존
- **사용 시기**: Btrfs 파일시스템 사용 시

### zfs
- **의미**: ZFS 파일시스템 사용
- **성능**: ✅ 좋음
- **안정성**: ⚠️ 파일시스템 의존
- **사용 시기**: ZFS 파일시스템 사용 시

## 알아야 할 것들

### overlay2의 장점

- **성능**: 빠른 이미지 레이어 관리
- **공간 효율**: 레이어 공유로 디스크 절약
- **안정성**: 널리 사용되고 검증됨
- **호환성**: 대부분의 Linux 배포판 지원

### 드라이버 변경 시

드라이버를 변경하면:
- 기존 이미지/컨테이너가 작동하지 않을 수 있음
- 데이터 마이그레이션 필요
- Docker 서비스 중지 필요

### 파일시스템 요구사항

일부 드라이버는 특정 파일시스템이 필요합니다:
- **btrfs**: Btrfs 파일시스템
- **zfs**: ZFS 파일시스템
- **overlay2**: ext4, xfs 등 (대부분 지원)

## 자주 발생하는 오류

### 드라이버를 변경했는데 작동 안 함
**원인**: 기존 데이터와 호환되지 않음

**해결 방법**:
1. 기존 이미지/컨테이너 백업
2. Docker 데이터 디렉토리 초기화
3. 새 드라이버로 재설정

### "Storage driver not supported" 오류
**원인**: 
- 커널이 해당 드라이버를 지원하지 않음
- 필요한 모듈이 로드되지 않음

**해결 방법**:
1. 커널 모듈 확인
2. 지원되는 드라이버 확인: `docker info`
3. 다른 드라이버 사용

### 성능이 느림
**원인**: 드라이버가 시스템에 최적화되지 않음

**해결 방법**:
1. `overlay2` 사용 (권장)
2. 파일시스템 확인
3. 디스크 I/O 성능 확인
