# SSL/TLS 암호화 (SSL Enable)

## 이 옵션이 하는 일

FTP 연결에 SSL/TLS 암호화를 사용할지 결정합니다. 활성화하면 데이터가 암호화되어 전송되어 보안이 강화됩니다. FTPS(FTP over SSL)라고도 합니다.

## 동작 방식

### 활성화 시 (ON, 권장)
- SSL/TLS 암호화 연결 사용
- 데이터 암호화
- 보안 강화
- SSL 인증서 필요

### 비활성화 시 (OFF)
- 평문 연결만 사용
- 데이터 암호화 안 됨
- 보안 위험

## 사용 시나리오

### 활성화가 권장되는 경우 (대부분)
- **외부 접속**: 인터넷을 통한 접속
- **보안**: 민감한 데이터 전송
- **프로덕션 환경**: 실제 사용 환경

### 비활성화가 가능한 경우
- **내부 네트워크만**: 로컬 네트워크에서만 접속
- **개발 환경**: 테스트 목적
- **임시 사용**: 빠른 설정 필요 시

## 알아야 할 것들

### SSL 인증서 필요

SSL을 사용하려면 인증서가 필요합니다:
- **자체 서명 인증서**: 개발/테스트용 (클라이언트 경고 발생)
- **Let's Encrypt**: 무료 공인 인증서 (권장)
- **상용 인증서**: 유료 인증서

### 인증서 설정

인증서 파일 위치:
- **인증서**: `/etc/ssl/certs/vsftpd.pem`
- **개인 키**: `/etc/ssl/private/vsftpd.key`

또는 하나의 파일에 통합:
- `/etc/ssl/certs/vsftpd.pem` (인증서 + 키)

### FTP 클라이언트 설정

SSL 활성화 시 클라이언트도 SSL을 지원해야 합니다:
- **FileZilla**: "FTPS" 또는 "FTP over TLS" 선택
- **WinSCP**: "FTP over TLS" 선택
- **명령줄**: `lftp` 등 SSL 지원 클라이언트 사용

## 자주 발생하는 오류

### "SSL connection failed" 오류
**원인**: 
- 인증서가 없음
- 인증서 경로가 잘못됨
- 인증서 권한 문제

**해결 방법**:
1. 인증서 생성 또는 설치
2. 인증서 경로 확인
3. 권한 설정: `chmod 600 /etc/ssl/certs/vsftpd.pem`

### 클라이언트에서 SSL 오류
**원인**: 자체 서명 인증서 사용

**해결 방법**:
1. 클라이언트에서 인증서 예외 추가
2. 또는 공인 인증서 사용

### 인증서 만료
**원인**: 인증서 유효 기간 만료

**해결 방법**:
1. 인증서 갱신
2. Let's Encrypt는 자동 갱신 설정
3. 새 인증서 설치
