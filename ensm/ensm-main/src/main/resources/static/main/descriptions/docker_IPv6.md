# IPv6 지원 (IPv6)

## 이 옵션이 하는 일

Docker가 IPv6를 지원할지 결정합니다. 활성화하면 컨테이너에서 IPv6 주소를 사용할 수 있습니다.

## 동작 방식

### 활성화 시 (ON)
- IPv6 주소 할당
- IPv6 네트워크 지원
- IPv4와 IPv6 모두 사용 가능

### 비활성화 시 (OFF, 기본값)
- IPv4만 사용
- IPv6 비활성화
- 대부분의 경우 충분

## 사용 시나리오

### 활성화가 필요한 경우
- **IPv6 네트워크**: IPv6를 사용하는 환경
- **IPv6 서비스**: IPv6로 서비스 제공
- **최신 표준**: IPv6 지원 필요

### 비활성화가 가능한 경우 (대부분)
- **IPv4만 사용**: 대부분의 환경
- **간단한 설정**: IPv6 불필요
- **기본값**: 대부분의 경우 충분

## 알아야 할 것들

### IPv6 주소 형식

IPv6 주소 예시:
- `2001:db8::1`
- `fe80::1`
- `::1` (localhost)

### 시스템 요구사항

IPv6 활성화 시:
- 시스템이 IPv6를 지원해야 함
- 네트워크 인터페이스에 IPv6 주소 필요
- 커널 모듈 로드 필요

### IPv4와 IPv6

Docker는 IPv4와 IPv6를 모두 지원할 수 있습니다:
- 활성화 시: 둘 다 사용
- 비활성화 시: IPv4만 사용

## 자주 발생하는 오류

### IPv6가 작동하지 않음
**확인 사항**:
1. 시스템이 IPv6를 지원하는지 확인
2. 네트워크 인터페이스에 IPv6 주소가 있는지 확인
3. 커널 모듈 로드 확인

### IPv6 활성화 후 문제 발생
**원인**: IPv6 설정 오류 또는 호환성 문제

**해결 방법**:
1. IPv6 비활성화
2. 또는 IPv6 설정 확인
3. 네트워크 구성 확인
