# 방화벽 포트 허용 (Firewall)

## 이 옵션이 하는 일

vsftpd FTP 서버가 사용하는 포트를 시스템 방화벽에서 자동으로 열어주는 기능입니다. FTP는 제어 포트(21)와 데이터 포트(PASV 범위) 모두 필요합니다.

## 왜 필요한가요?

FTP 서버는 네트워크의 다른 컴퓨터에서 접근할 수 있어야 합니다. 방화벽이 포트를 차단하면 FTP 접속이 실패합니다.

## 동작 방식

### 활성화 시 (ON)
- TCP 21번 포트 허용 (제어 연결)
- PASV 포트 범위 허용 (데이터 연결)
- 외부에서 FTP 접속 가능

### 비활성화 시 (OFF)
- 방화벽 규칙 추가 안 됨
- 로컬에서만 FTP 접속 가능
- 외부 접근 불가

## 알아야 할 것들

### FTP 포트 요구사항

FTP는 여러 포트가 필요합니다:
- **포트 21**: 제어 연결 (필수)
- **PASV 포트 범위**: 데이터 연결 (PASV 모드 사용 시)

PASV 모드 사용 시 포트 범위도 함께 열어야 합니다.

### PASV 포트 범위

일반적으로 다음 범위를 사용합니다:
- `21100-21110`: 작은 범위
- `50000-51000`: 넓은 범위 (많은 동시 연결)

## 자주 발생하는 오류

### 제어 연결은 되는데 파일 전송이 안 됨
**원인**: PASV 포트 범위가 방화벽에서 열리지 않음

**해결 방법**:
1. PASV 포트 범위 확인
2. 방화벽에서 해당 범위 열기
3. PASV 모드 활성화 확인

### 방화벽 규칙이 적용되지 않음
**확인 사항**:
1. 방화벽 서비스가 실행 중인지 확인
2. 규칙이 올바르게 추가되었는지 확인
3. 방화벽 재시작 또는 리로드

### 외부에서 접근이 안 됨
**확인 사항**:
1. 클라우드 환경: 보안 그룹에서 포트 허용
2. 홈 서버: 라우터 포트 포워딩 설정
3. vsftpd가 외부 인터페이스에서 수신하도록 설정
