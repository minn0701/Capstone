# 웹 인터페이스 포트 (Port)

## 이 옵션이 하는 일

Home Assistant 웹 인터페이스가 클라이언트의 요청을 받을 포트 번호를 지정합니다. 브라우저에서 이 포트로 접속하여 홈 오토메이션을 제어할 수 있습니다.

## 기본값

- **기본값**: 8123
- **표준 포트**: 8123 (Home Assistant 기본 포트)

## 포트 설정

### 표준 포트 (8123)
```
8123        → Home Assistant 기본 포트 (권장)
```
→ 대부분의 경우 이 포트 사용

### 대체 포트
```
8124        → 다른 서비스와 충돌 시
8080        → 개발/테스트용
```
→ 특수한 경우에만 사용

## 알아야 할 것들

### 접속 방법

브라우저에서 접속:
- 로컬: `http://서버주소:8123`
- 외부: DDNS 설정 시 `http://도메인:8123`

### 초기 설정

첫 접속 시:
- 관리자 계정 생성 필요
- 초기 설정 마법사 실행
- 통합 구성 요소 설정

### 보안 고려사항

**중요**: Home Assistant는 홈 오토메이션을 제어하므로:
- 강력한 비밀번호 사용
- 외부 접속 시 HTTPS 권장
- 방화벽으로 접근 제한 가능

## 자주 발생하는 오류

### "Connection refused" 오류
**원인**: 
- 포트가 방화벽에서 차단됨
- Home Assistant 서비스가 실행되지 않음

**해결 방법**:
1. Home Assistant 서비스 상태 확인
2. 방화벽에서 포트 열기
3. 서비스 재시작

### 외부에서 접속이 안 됨
**확인 사항**:
1. 방화벽 설정 확인
2. DDNS 설정 확인 (외부 접속 시)
3. 라우터 포트 포워딩 확인

### 초기 설정이 안 됨
**원인**: 첫 접속 시 관리자 계정 생성 필요

**해결 방법**:
1. 브라우저에서 포트로 접속
2. 초기 설정 마법사 따라하기
3. 관리자 계정 생성
