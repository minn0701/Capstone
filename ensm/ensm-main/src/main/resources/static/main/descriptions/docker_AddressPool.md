# 기본 주소 풀 (Default Address Pool)

## 이 옵션이 하는 일

Docker가 컨테이너 네트워크에 할당할 IP 주소 범위를 지정합니다. 여러 네트워크를 사용할 때 IP 주소 충돌을 방지합니다.

## 기본값

- **기본값**: 없음 (Docker 기본 범위 사용)
- **일반적인 설정**: `172.17.0.0/16` (Docker 기본)

## 설정 예시

### Docker 기본 범위
```
172.17.0.0/16
```
→ Docker 기본 IP 범위

### 사용자 정의 범위
```
10.20.0.0/16
192.168.100.0/24
```
→ 사용자 정의 IP 범위

### 여러 범위
```
172.17.0.0/16, 172.18.0.0/16
```
→ 여러 IP 범위 지정 (쉼표로 구분)

## 알아야 할 것들

### CIDR 표기법

IP 주소 범위를 지정하는 방법:
- `172.17.0.0/16` → 172.17.0.0 ~ 172.17.255.255 (65,536개 IP)
- `192.168.100.0/24` → 192.168.100.0 ~ 192.168.100.255 (256개 IP)

### IP 주소 충돌 방지

여러 Docker 네트워크 사용 시:
- 각 네트워크에 다른 IP 범위 할당
- 충돌 방지
- 관리 용이

### 네트워크와의 관계

각 Docker 네트워크는 IP 범위를 할당받습니다:
- 첫 번째 네트워크: 첫 번째 범위
- 두 번째 네트워크: 두 번째 범위
- 등등...

## 자주 발생하는 오류

### "Pool overlaps with other one" 오류
**원인**: IP 범위가 기존 네트워크와 겹침

**해결 방법**:
1. 겹치지 않는 IP 범위 사용
2. 기존 네트워크 확인
3. IP 범위 재설정

### IP 주소 부족
**원인**: IP 범위가 너무 작음

**해결 방법**:
1. 더 큰 범위 사용 (예: /16 → /12)
2. 또는 여러 범위 지정

### 호스트 네트워크와 충돌
**원인**: Docker IP 범위가 호스트 네트워크와 겹침

**해결 방법**:
1. 호스트 네트워크 확인
2. 겹치지 않는 범위 사용
3. 일반적으로 172.17.0.0/16 사용 권장
