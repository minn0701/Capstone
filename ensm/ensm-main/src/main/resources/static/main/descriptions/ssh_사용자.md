# SSH 사용자

## 개요

원격 서버의 사용자명을 지정하는 설정입니다. 공개키를 복사할 원격 서버의 사용자 계정입니다.

## 설정 방법

원격 서버의 사용자명을 입력합니다:

```
root
```

또는:

```
admin
```

## 주요 특징

- **원격 사용자**: 공개키를 복사할 원격 서버의 사용자
- **홈 디렉토리**: 해당 사용자의 홈 디렉토리에 키가 복사됩니다
- **권한**: 원격 서버에 접속할 수 있는 사용자여야 합니다

## 일반적인 사용 예시

```
root
admin
user
ubuntu
centos
```

## 주의사항

- **사용자 존재**: 원격 서버에 해당 사용자가 존재해야 합니다
- **접속 권한**: 해당 사용자로 SSH 접속이 가능해야 합니다
- **홈 디렉토리**: 사용자의 홈 디렉토리에 `.ssh` 디렉토리가 생성됩니다

## 키 복사 위치

공개키는 다음 위치에 복사됩니다:

```
~/.ssh/authorized_keys
```

또는:

```
/home/사용자명/.ssh/authorized_keys
```

## 권장 사항

1. **root 사용자**: 보안상 root 사용자보다는 일반 사용자 사용 권장
2. **전용 사용자**: SSH 접속 전용 사용자 생성 권장
3. **최소 권한**: 필요한 최소 권한만 가진 사용자 사용

## 보안 고려사항

- **root 접속**: root 사용자 직접 접속은 보안 위험이 있으므로 주의
- **일반 사용자**: 일반 사용자로 접속 후 `sudo` 사용 권장
- **키 관리**: 여러 사용자에 키를 복사할 때 주의
