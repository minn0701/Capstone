# 기본 브랜치 이름 (Default Branch)

## 이 옵션이 하는 일

새 Git 저장소를 초기화할 때 생성되는 기본 브랜치의 이름을 지정합니다. 전통적으로 `master`를 사용했지만, 최근에는 `main`을 권장합니다.

## 기본값

- **기본값**: `main` (최신 Git)
- **구버전**: `master` (전통적)

## 선택지 설명

### main
- **의미**: 메인 브랜치
- **사용 시기**: **권장** (최신 표준)
- **장점**: 중립적이고 명확함

### master
- **의미**: 마스터 브랜치 (전통적)
- **사용 시기**: 레거시 프로젝트, 호환성
- **참고**: 일부 조직에서 여전히 사용

### develop
- **의미**: 개발 브랜치
- **사용 시기**: Git Flow 워크플로우
- **참고**: 일반적으로는 `main` 권장

## 알아야 할 것들

### 브랜치 이름 변경

기존 저장소의 브랜치 이름 변경:

```bash
# 브랜치 이름 변경
git branch -m master main

# 원격 저장소에 푸시
git push -u origin main

# 원격의 master 브랜치 삭제
git push origin --delete master
```

### GitHub/GitLab 기본값

대부분의 호스팅 서비스가 `main`을 기본값으로 사용:
- GitHub: `main` (기본값)
- GitLab: `main` (기본값)
- Bitbucket: `main` (기본값)

### 협업 시 주의

팀 프로젝트에서는:
- 팀 전체가 같은 기본 브랜치 이름 사용
- 일관성 유지
- 문서에 명시

## 자주 발생하는 오류

### 브랜치 이름이 다름
**원인**: 각자 다른 기본 브랜치 이름 사용

**해결 방법**:
1. 팀 전체가 같은 이름 사용
2. 저장소별로 설정 가능 (로컬 설정)

### 원격 저장소와 불일치
**원인**: 로컬은 `main`, 원격은 `master`

**해결 방법**:
1. 원격 저장소의 기본 브랜치 확인
2. 로컬 브랜치 이름 변경
3. 또는 원격 브랜치 이름 변경
