# SSH 포트

## 개요

SSH 서비스 포트 번호를 지정하는 설정입니다. 원격 서버의 SSH 서비스가 실행 중인 포트를 지정합니다.

## 설정 방법

SSH 포트 번호를 숫자로 입력합니다:

```
22
```

## 주요 특징

- **기본 포트**: SSH의 기본 포트는 22입니다
- **커스텀 포트**: 보안을 위해 다른 포트를 사용할 수 있습니다
- **포트 범위**: 1-65535 범위의 포트 사용 가능

## 일반적인 사용 예시

```
# 기본 포트
22

# 커스텀 포트
2222
2200
10022
```

## 보안 고려사항

- **기본 포트 변경**: 보안을 위해 기본 포트(22)를 변경하는 것을 권장합니다
- **포트 스캔**: 기본 포트는 자동화된 공격의 대상이 될 수 있습니다
- **방화벽**: 사용하는 포트를 방화벽에서 열어야 합니다

## 주의사항

- **포트 열림**: 방화벽에서 지정한 포트가 열려있어야 합니다
- **서비스 실행**: 원격 서버에서 SSH 서비스가 해당 포트에서 실행 중이어야 합니다
- **권한**: 1024 이하의 포트는 root 권한이 필요합니다

## 포트 확인

원격 서버의 SSH 포트를 확인하려면:

```bash
# SSH 서비스 포트 확인
ss -tlnp | grep ssh

# 또는
netstat -tlnp | grep ssh
```

## 권장 설정

- **기본 환경**: 22 (테스트 및 개발)
- **프로덕션**: 2222 이상의 커스텀 포트 (보안 강화)

## 포트 변경 방법

원격 서버의 SSH 포트를 변경하려면 `/etc/ssh/sshd_config` 파일을 수정:

```
Port 2222
```

수정 후 SSH 서비스 재시작:

```bash
systemctl restart sshd
```
