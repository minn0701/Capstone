# 방화벽 포트 허용 (Firewall)

## 이 옵션이 하는 일

BIND DNS 서버가 사용하는 포트(53번)를 시스템 방화벽에서 자동으로 열어주는 기능입니다. DNS는 UDP와 TCP 모두 사용하므로 두 프로토콜 모두 허용해야 합니다.

## 왜 필요한가요?

DNS 서버는 네트워크의 다른 컴퓨터에서 접근할 수 있어야 합니다. 방화벽이 포트를 차단하면 DNS 쿼리가 실패합니다.

## 동작 방식

### 활성화 시 (ON)
- UDP 53번 포트 허용 (주로 사용)
- TCP 53번 포트 허용 (큰 응답용)
- 외부에서 DNS 쿼리 가능

### 비활성화 시 (OFF)
- 방화벽 규칙 추가 안 됨
- 로컬에서만 DNS 쿼리 가능
- 외부 접근 불가

## 알아야 할 것들

### UDP와 TCP 모두 필요

DNS는 두 프로토콜을 모두 사용합니다:
- **UDP 53**: 일반적인 DNS 쿼리 (대부분)
- **TCP 53**: 큰 응답이나 존 전송 시 사용

방화벽에서 둘 다 열어야 합니다.

### 내부 vs 외부 DNS

- **내부 DNS**: 회사나 가정 네트워크 내부에서만 사용
  - 방화벽에서 내부 네트워크만 허용 가능
- **공용 DNS**: 인터넷에서 접근 가능한 DNS 서버
  - 외부 접근 허용 필요

## 자주 발생하는 오류

### 방화벽 규칙이 적용되지 않음
**확인 사항**:
1. 방화벽 서비스가 실행 중인지 확인
2. 규칙이 올바르게 추가되었는지 확인
3. 방화벽 재시작 또는 리로드

### UDP는 되는데 TCP가 안 됨
**원인**: TCP 포트가 열리지 않음

**해결 방법**:
- DNS는 UDP와 TCP 모두 필요
- 두 프로토콜 모두 허용 확인

### 외부에서 접근이 안 됨
**확인 사항**:
1. 클라우드 환경: 보안 그룹에서 53번 포트 허용
2. 홈 서버: 라우터 포트 포워딩 설정
3. BIND가 외부 인터페이스에서 수신하도록 설정
