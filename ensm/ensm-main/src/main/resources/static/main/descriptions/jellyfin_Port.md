# 웹 인터페이스 포트 (Port)

## 이 옵션이 하는 일

Jellyfin 미디어 서버의 웹 인터페이스가 클라이언트의 요청을 받을 포트 번호를 지정합니다. 브라우저에서 이 포트로 접속하여 미디어를 시청할 수 있습니다.

## 기본값

- **기본값**: 8096
- **표준 포트**: 8096 (Jellyfin 기본 포트)

## 포트 설정

### 표준 포트 (8096)
```
8096        → Jellyfin 기본 포트 (권장)
```
→ 대부분의 경우 이 포트 사용

### 대체 포트
```
8097        → 다른 서비스와 충돌 시
8080        → 개발/테스트용
```
→ 특수한 경우에만 사용

## 알아야 할 것들

### HTTPS 포트와의 관계

Jellyfin은 HTTP와 HTTPS를 모두 지원합니다:
- **HTTP 포트**: 기본 8096
- **HTTPS 포트**: 기본 8920 (HTTPS 활성화 시)

### 접속 방법

브라우저에서 접속:
- HTTP: `http://서버주소:8096`
- HTTPS: `https://서버주소:8920`

### 방화벽 설정

외부에서 접속하려면:
- 방화벽에서 포트 열기
- 클라우드 환경: 보안 그룹 설정
- 라우터 포트 포워딩 (홈 서버)

## 자주 발생하는 오류

### "Connection refused" 오류
**원인**: 
- 포트가 방화벽에서 차단됨
- Jellyfin 서비스가 실행되지 않음

**해결 방법**:
1. Jellyfin 서비스 상태 확인: `sudo systemctl status jellyfin`
2. 방화벽에서 포트 열기
3. 서비스 재시작

### 포트 충돌
**원인**: 다른 서비스가 같은 포트 사용

**해결 방법**:
1. 포트 사용 확인: `sudo netstat -tulpn | grep :8096`
2. 다른 포트 사용
3. 또는 충돌하는 서비스 중지

### 외부에서 접속이 안 됨
**확인 사항**:
1. 방화벽 설정 확인
2. 클라우드 환경: 보안 그룹 확인
3. 라우터 포트 포워딩 확인
