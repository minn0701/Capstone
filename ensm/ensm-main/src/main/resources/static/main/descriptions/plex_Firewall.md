# 방화벽 포트 허용 (Firewall)

## 이 옵션이 하는 일

Plex 미디어 서버가 사용하는 포트를 시스템 방화벽에서 자동으로 열어주는 기능입니다. 외부에서 Plex 서버에 접속할 수 있도록 합니다.

## 왜 필요한가요?

Plex 서버는 네트워크의 다른 기기(스마트 TV, 스마트폰 등)에서 접근할 수 있어야 합니다. 방화벽이 포트를 차단하면 클라이언트가 서버에 접속할 수 없습니다.

## 동작 방식

### 활성화 시 (ON)
- TCP 32400 포트 허용 (메인 서버)
- 외부에서 Plex 접속 가능
- 원격 접근 허용 (원격 접근 활성화 시)

### 비활성화 시 (OFF)
- 방화벽 규칙 추가 안 됨
- 로컬에서만 접속 가능
- 외부 접근 불가

## 알아야 할 것들

### Plex 포트

Plex는 여러 포트를 사용합니다:
- **32400**: 메인 서버 포트 (필수)
- **32401**: 추가 서비스 포트
- **32469**: DLNA 서비스 (선택사항)

### 원격 접근

원격 접근 활성화 시:
- 인터넷을 통한 접속 가능
- Plex 계정으로 자동 연결
- 방화벽 설정 필수

## 자주 발생하는 오류

### 외부에서 접속이 안 됨
**확인 사항**:
1. 방화벽 설정 확인
2. 원격 접근 활성화 확인
3. 클라우드 환경: 보안 그룹 확인
4. 라우터 포트 포워딩 확인

### 방화벽 규칙이 적용되지 않음
**확인 사항**:
1. 방화벽 서비스가 실행 중인지 확인
2. 규칙이 올바르게 추가되었는지 확인
3. 방화벽 재시작 또는 리로드
