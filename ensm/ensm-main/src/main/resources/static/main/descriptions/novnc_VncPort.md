# VNC 서버 포트 (VNC Port)

## 이 옵션이 하는 일

연결할 VNC 서버가 사용하는 포트 번호를 지정합니다. VNC 서버는 일반적으로 5900번대 포트를 사용합니다.

## 기본값

- **기본값**: 5900
- **표준 포트**: 5900 (VNC 디스플레이 :0)

## 포트 설정

### 표준 포트
```
5900        → 디스플레이 :0 (기본)
5901        → 디스플레이 :1
5902        → 디스플레이 :2
```

### 포트 번호 규칙

VNC 포트 번호 = 5900 + 디스플레이 번호:
- 디스플레이 :0 → 포트 5900
- 디스플레이 :1 → 포트 5901
- 디스플레이 :2 → 포트 5902

## 알아야 할 것들

### VNC 디스플레이

Linux에서 여러 디스플레이를 사용할 수 있습니다:
- **:0**: 첫 번째 디스플레이 (기본)
- **:1**: 두 번째 디스플레이
- **:2**: 세 번째 디스플레이

### VNC 서버 확인

VNC 서버가 어떤 포트에서 실행 중인지 확인:

```bash
# VNC 프로세스 확인
ps aux | grep vnc

# 포트 사용 확인
sudo netstat -tulpn | grep 5900
```

### 방화벽 설정

VNC 서버 포트도 방화벽에서 열어야 합니다:
- TCP 5900: VNC 서버 (기본)
- 또는 사용하는 포트

## 자주 발생하는 오류

### "Connection refused" 오류
**원인**: 
- VNC 서버가 해당 포트에서 실행되지 않음
- 포트 번호가 잘못됨

**해결 방법**:
1. VNC 서버 포트 확인
2. 올바른 포트 번호 입력
3. VNC 서버 재시작

### 포트가 다름
**원인**: VNC 서버가 다른 포트에서 실행 중

**해결 방법**:
1. VNC 서버 설정 확인
2. 실제 사용 중인 포트 확인
3. noVNC 설정에 올바른 포트 입력
