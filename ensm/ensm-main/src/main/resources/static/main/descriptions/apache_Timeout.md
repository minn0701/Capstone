# 요청 타임아웃 (Timeout)

## 이 옵션이 하는 일

클라이언트로부터 요청을 받은 후 응답을 보내기까지의 최대 대기 시간을 초 단위로 지정합니다. 이 시간 내에 응답을 완료하지 못하면 연결이 끊어집니다.

## 기본값

- **기본값**: 60초
- **권장 범위**: 30 ~ 300초

## 타임아웃 값 선택 가이드

### 짧은 타임아웃 (30-60초)
- **장점**: 느린 요청으로 인한 리소스 점유 방지
- **단점**: 큰 파일 업로드/다운로드 시 문제 발생 가능
- **사용 시기**: 일반적인 웹사이트, 빠른 응답이 중요한 경우

### 중간 타임아웃 (60-120초)
- **장점**: 대부분의 요청 처리 가능, 균형잡힌 설정
- **단점**: 매우 큰 파일은 여전히 문제 가능
- **사용 시기**: **대부분의 경우 권장**

### 긴 타임아웃 (120-300초)
- **장점**: 큰 파일 업로드/다운로드 가능
- **단점**: 느린 요청이 리소스를 오래 점유
- **사용 시기**: 파일 업로드 서비스, 대용량 다운로드

### 매우 긴 타임아웃 (300초 이상)
- **장점**: 매우 큰 파일 처리 가능
- **단점**: 공격에 취약, 리소스 점유 문제
- **사용 시기**: 특수한 경우만 (일반적으로 권장하지 않음)

## 설정 예시

```
30        → 빠른 타임아웃 (일반 웹사이트)
60        → 기본값 (권장)
120       → 파일 업로드 서비스
300       → 대용량 파일 처리
```

## 알아야 할 것들

### 타임아웃이 발생하는 경우

1. **느린 네트워크**: 클라이언트의 네트워크가 느려서 데이터 전송이 오래 걸림
2. **큰 파일 처리**: 대용량 파일 업로드/다운로드
3. **느린 데이터베이스 쿼리**: 복잡한 쿼리 실행 시간이 오래 걸림
4. **외부 API 호출**: 외부 서비스 응답 대기

### 타임아웃과 KeepAlive

`Timeout`은 단일 요청의 최대 처리 시간이고, `KeepAliveTimeout`은 연결 유지 시간입니다. 둘은 다른 설정입니다.

### PHP와의 관계

PHP의 `max_execution_time` 설정도 함께 고려해야 합니다:
- Apache `Timeout` > PHP `max_execution_time` 권장
- 그렇지 않으면 PHP가 실행 중인데 Apache 연결이 끊어질 수 있음

## 자주 발생하는 오류

### "Request timeout" 오류
**원인**: 
- 요청 처리 시간이 타임아웃 값보다 김
- 네트워크가 느림
- 서버 처리 속도가 느림

**해결 방법**:
1. 타임아웃 값을 늘림 (예: 60 → 120)
2. 서버 성능 개선
3. 요청 처리 로직 최적화

### 큰 파일 업로드가 실패함
**원인**: 타임아웃이 너무 짧음

**해결 방법**:
1. 타임아웃 값 증가 (예: 300초)
2. PHP `max_execution_time`도 함께 증가
3. `upload_max_filesize`, `post_max_size` 확인

### 서버 리소스가 부족함
**원인**: 타임아웃이 너무 길어서 느린 요청이 리소스를 오래 점유

**해결 방법**:
1. 타임아웃 값을 줄임 (예: 300 → 60)
2. 동시 연결 수 제한 (`MaxRequestWorkers`)
3. 느린 요청 모니터링 및 최적화

### 타임아웃을 늘렸는데도 안 됨
**확인 사항**:
1. Apache 설정이 실제로 적용되었는지 확인
2. 프록시나 로드 밸런서의 타임아웃도 확인
3. PHP나 다른 애플리케이션의 타임아웃 설정 확인
