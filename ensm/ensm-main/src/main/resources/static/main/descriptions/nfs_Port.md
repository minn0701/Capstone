# NFS 서버 포트 (Port)

## 이 옵션이 하는 일

NFS(Network File System) 서버가 파일 공유 요청을 받을 포트 번호를 지정합니다. NFS는 기본적으로 2049번 포트를 사용합니다.

## 기본값

- **기본값**: 2049
- **표준 포트**: 2049 (NFS 프로토콜 표준)

## 포트 설정

### 표준 포트 (2049)
```
2049        → 표준 NFS 포트 (권장)
```
→ 모든 NFS 클라이언트가 기본적으로 사용하는 포트

### 대체 포트
```
20490       → 개발/테스트용 포트
```
→ 특수한 경우에만 사용 (일반적으로 권장하지 않음)

## 알아야 할 것들

### NFS의 여러 포트

NFS는 여러 포트를 사용합니다:
- **포트 2049**: NFS 서버 (메인)
- **포트 111**: RPC 바인더 (포트 매핑)
- **포트 20048**: Mount 데몬
- **포트 32765-32768**: Statd, Lockd 등

### 방화벽 설정

NFS를 사용하려면 여러 포트를 열어야 합니다:
- TCP/UDP 2049: NFS 서버
- TCP/UDP 111: RPC 바인더
- TCP/UDP 20048: Mount 데몬
- TCP/UDP 32765-32768: 기타 서비스

### 보안 고려사항

**중요**: NFS는 인증이 약하므로:
- 내부 네트워크에서만 사용 권장
- 외부 접근은 VPN 등으로 보호
- 방화벽으로 접근 제한

## 자주 발생하는 오류

### "Connection refused" 오류
**원인**: 
- 포트가 방화벽에서 차단됨
- NFS 서비스가 실행되지 않음

**해결 방법**:
1. NFS 서비스 상태 확인: `sudo systemctl status nfs-server`
2. 방화벽에서 포트 열기
3. RPC 서비스 확인: `sudo systemctl status rpcbind`

### 마운트가 안 됨
**확인 사항**:
1. 모든 필요한 포트가 열려있는지 확인
2. RPC 서비스가 실행 중인지 확인
3. `/etc/exports` 설정 확인

### 외부에서 접근이 안 됨
**원인**: 보안상 내부 네트워크만 허용되어 있음

**해결 방법**:
- 내부 네트워크에서만 사용하는 것이 권장됨
- 외부 접근이 필요하면 VPN 사용
