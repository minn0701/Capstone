# 유휴 세션 타임아웃 (Idle Timeout)

## 이 옵션이 하는 일

FTP 클라이언트가 아무 작업도 하지 않고 대기할 수 있는 최대 시간(초)을 지정합니다. 이 시간이 지나면 연결이 자동으로 끊어집니다.

## 기본값

- **기본값**: 600초 (10분)
- **권장 범위**: 300-1800초 (5-30분)

## 설정 예시

### 짧은 타임아웃
```
300        → 5분
600        → 10분 (기본값)
```
→ 빠른 타임아웃, 리소스 절약

### 중간 타임아웃
```
900        → 15분
1200       → 20분
```
→ 균형잡힌 설정

### 긴 타임아웃
```
1800       → 30분
3600       → 1시간
```
→ 긴 대기 시간 허용

## 알아야 할 것들

### 유휴 세션이란?

클라이언트가 연결되어 있지만:
- 파일 전송 없음
- 명령 입력 없음
- 대기 상태

### 리소스 관리

유휴 세션은 서버 리소스를 사용합니다:
- 메모리 점유
- 연결 슬롯 사용
- 다른 사용자 접근 차단 가능

타임아웃으로 불필요한 연결 정리.

### 사용자 경험

타임아웃이 너무 짧으면:
- 사용자가 불편함
- 작업 중 연결 끊김

타임아웃이 너무 길면:
- 리소스 낭비
- 서버 부하 증가

## 자주 발생하는 오류

### 작업 중 연결이 끊김
**원인**: 타임아웃이 너무 짧음

**해결 방법**:
1. 타임아웃 값 증가 (예: 1800초)
2. 또는 클라이언트에서 주기적으로 명령 전송

### 유휴 연결이 너무 많음
**원인**: 타임아웃이 너무 김

**해결 방법**:
1. 타임아웃 값 감소 (예: 600초)
2. 서버 리소스 확인
