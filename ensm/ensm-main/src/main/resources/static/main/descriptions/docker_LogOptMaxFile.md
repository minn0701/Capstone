# 최대 로그 파일 개수 (Log Opt Max File)

## 이 옵션이 하는 일

컨테이너당 유지할 최대 로그 파일 개수를 지정합니다. 이 개수를 초과하면 가장 오래된 로그 파일이 자동으로 삭제됩니다.

## 기본값

- **기본값**: `3`
- **일반적인 설정**: 3-10

## 설정 예시

### 적은 개수
```
1
2
```
→ 최소한의 로그만 유지, 디스크 절약

### 기본 개수
```
3
5
```
→ 적절한 로그 보관 (권장)

### 많은 개수
```
10
20
```
→ 많은 로그 보관, 디스크 사용 증가

## 알아야 할 것들

### 로그 파일 이름

로그 파일은 다음과 같이 이름이 지정됩니다:
- `<container-id>-json.log`: 현재 로그
- `<container-id>-json.log.1`: 첫 번째 백업
- `<container-id>-json.log.2`: 두 번째 백업
- 등등...

### 디스크 공간 계산

최대 디스크 사용량:
- **크기**: `max_log_size` (예: 10m)
- **개수**: `log_opt_max_file` (예: 3)
- **최대 사용량**: 10m × 3 = 30MB (컨테이너당)

### 로그 보관 기간

파일 개수에 따라:
- **3개**: 최근 3개 로그 파일 보관
- **10개**: 최근 10개 로그 파일 보관
- 더 많은 개수 = 더 긴 로그 보관 기간

## 자주 발생하는 오류

### 디스크 공간 부족
**원인**: 로그 파일이 너무 많음

**해결 방법**:
1. `log_opt_max_file` 값 감소 (예: 10 → 3)
2. `max_log_size` 값 감소
3. 오래된 로그 파일 수동 삭제

### 오래된 로그가 필요함
**원인**: 파일 개수가 너무 적음

**해결 방법**:
1. `log_opt_max_file` 값 증가 (예: 3 → 10)
2. 더 많은 로그 보관
