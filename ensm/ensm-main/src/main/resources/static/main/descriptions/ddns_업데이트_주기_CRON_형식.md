# DDNS 업데이트 주기 (CRON 형식)

## 개요

DDNS 업데이트 주기를 CRON 형식으로 지정하는 설정입니다. 지정한 주기마다 현재 IP 주소를 확인하고 변경된 경우 DNS 레코드를 업데이트합니다.

## 설정 방법

CRON 형식으로 업데이트 주기를 지정합니다:

```
*/5 * * * *
```

## CRON 형식

CRON 형식은 5개의 필드로 구성됩니다:

```
분 시 일 월 요일
*  *  *  *  *
```

- **분**: 0-59
- **시**: 0-23
- **일**: 1-31
- **월**: 1-12
- **요일**: 0-7 (0과 7은 일요일)

## 일반적인 사용 예시

```
# 5분마다
*/5 * * * *

# 10분마다
*/10 * * * *

# 1시간마다
0 * * * *

# 매일 자정
0 0 * * *

# 매일 오전 9시
0 9 * * *
```

## 주기 선택 가이드

- **빠른 업데이트 (1-5분)**: IP가 자주 변경되는 경우
- **일반 업데이트 (5-15분)**: 일반적인 DDNS 사용
- **느린 업데이트 (30분-1시간)**: IP가 안정적인 경우

## 주의사항

- **API 제한**: Cloudflare API 호출 제한을 고려해야 합니다
- **불필요한 업데이트**: IP가 변경되지 않아도 API를 호출합니다
- **네트워크 부하**: 너무 짧은 주기는 네트워크 부하를 증가시킵니다

## 권장 설정

일반적인 DDNS 사용 시 권장 설정:

- **동적 IP**: `*/5 * * * *` (5분마다)
- **안정적 IP**: `0 * * * *` (1시간마다)

## CRON 표현식 예시

| 표현식 | 의미 |
|--------|------|
| `*/5 * * * *` | 5분마다 |
| `*/10 * * * *` | 10분마다 |
| `0 * * * *` | 매시간 정각 |
| `0 */2 * * *` | 2시간마다 |
| `0 0 * * *` | 매일 자정 |
