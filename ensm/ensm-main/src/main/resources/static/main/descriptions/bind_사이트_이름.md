# BIND Zone 파일 사이트 이름

## 개요

Zone 파일 내에서 도메인의 기본 이름을 지정하는 설정입니다. `@` 기호로 표현되며, Zone 파일의 도메인명을 의미합니다.

## 설정 방법

Zone 파일 내에서:

```
$TTL 3600
@       IN SOA  ns1.example.com. admin.example.com. (
                2024010101
                3600
                1800
                604800
                86400
        )
```

## 주요 특징

- **@ 기호**: Zone 파일의 도메인명을 나타냅니다
- **루트 도메인**: `example.com` Zone 파일에서 `@`는 `example.com`을 의미
- **SOA 레코드**: 반드시 `@`로 시작해야 합니다

## 일반적인 사용 예시

```
$TTL 3600
; @는 example.com을 의미
@       IN SOA  ns1.example.com. admin.example.com. (
                2024010101
                3600
                1800
                604800
                86400
        )

; 루트 도메인 A 레코드
@       IN A    192.168.1.100

; 서브도메인
www     IN A    192.168.1.100
mail    IN A    192.168.1.200
```

## 주의사항

- **SOA 필수**: Zone 파일에는 반드시 `@`로 시작하는 SOA 레코드가 있어야 합니다
- **도메인 끝 점**: FQDN은 끝에 점(`.`)을 붙여야 합니다
- **대소문자**: 레코드 타입(IN, A, NS 등)은 대문자로 작성하는 것이 관례입니다
