# 방화벽 포트 허용 (Firewall)

## 이 옵션이 하는 일

Jellyfin 미디어 서버가 사용하는 포트를 시스템 방화벽에서 자동으로 열어주는 기능입니다. HTTP와 HTTPS 포트 모두 필요합니다.

## 왜 필요한가요?

Jellyfin 서버는 네트워크의 다른 기기에서 접근할 수 있어야 합니다. 방화벽이 포트를 차단하면 클라이언트가 서버에 접속할 수 없습니다.

## 동작 방식

### 활성화 시 (ON)
- HTTP 포트(기본: 8096) 허용
- HTTPS 포트(기본: 8920) 허용 (HTTPS 활성화 시)
- 외부에서 Jellyfin 접속 가능

### 비활성화 시 (OFF)
- 방화벽 규칙 추가 안 됨
- 로컬에서만 접속 가능
- 외부 접근 불가

## 알아야 할 것들

### HTTP와 HTTPS 포트

Jellyfin은 두 포트를 사용할 수 있습니다:
- **HTTP 포트**: 기본 8096
- **HTTPS 포트**: 기본 8920 (HTTPS 활성화 시)

### 방화벽 설정

외부 접속을 허용하려면:
- 방화벽에서 포트 열기
- 클라우드 환경: 보안 그룹 설정
- 라우터 포트 포워딩 (홈 서버)

## 자주 발생하는 오류

### 외부에서 접속이 안 됨
**확인 사항**:
1. 방화벽 설정 확인
2. 클라우드 환경: 보안 그룹 확인
3. 라우터 포트 포워딩 확인
4. Jellyfin 서비스 상태 확인

### 방화벽 규칙이 적용되지 않음
**확인 사항**:
1. 방화벽 서비스가 실행 중인지 확인
2. 규칙이 올바르게 추가되었는지 확인
3. 방화벽 재시작 또는 리로드
