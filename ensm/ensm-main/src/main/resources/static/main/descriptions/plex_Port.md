# 미디어 서버 포트 (Port)

## 이 옵션이 하는 일

Plex 미디어 서버가 클라이언트의 요청을 받을 포트 번호를 지정합니다. Plex 클라이언트(앱, 웹 브라우저)가 이 포트를 통해 서버에 접속합니다.

## 기본값

- **기본값**: 32400
- **표준 포트**: 32400 (Plex 기본 포트)

## 포트 설정

### 표준 포트 (32400)
```
32400        → Plex 기본 포트 (권장)
```
→ 대부분의 경우 이 포트 사용

### 대체 포트
```
32401        → 다른 서비스와 충돌 시
8080         → 개발/테스트용
```
→ 특수한 경우에만 사용

## 알아야 할 것들

### Plex의 여러 포트

Plex는 여러 포트를 사용합니다:
- **32400**: 메인 서버 포트 (필수)
- **32401**: 추가 서비스 포트
- **32469**: DLNA 서비스 (선택사항)

### 접속 방법

Plex 클라이언트에서 접속:
- 로컬: `http://서버주소:32400`
- 원격: Plex 계정으로 자동 연결 (원격 접근 활성화 시)

### 원격 접근

`enableRemoteAccess` 옵션과 함께 사용:
- 활성화: 인터넷을 통한 접속 가능
- 비활성화: 로컬 네트워크만

## 자주 발생하는 오류

### "Connection refused" 오류
**원인**: 
- 포트가 방화벽에서 차단됨
- Plex 서비스가 실행되지 않음

**해결 방법**:
1. Plex 서비스 상태 확인
2. 방화벽에서 포트 열기
3. 서비스 재시작

### 원격 접속이 안 됨
**확인 사항**:
1. `enableRemoteAccess` 활성화 확인
2. 방화벽 설정 확인
3. Plex 계정 연결 확인
4. 라우터 포트 포워딩 확인

### 포트 충돌
**원인**: 다른 서비스가 같은 포트 사용

**해결 방법**:
1. 포트 사용 확인
2. 다른 포트 사용
3. 또는 충돌하는 서비스 중지
