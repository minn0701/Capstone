# 사용자 목록 사용 (Userlist Enable)

## 이 옵션이 하는 일

특정 사용자 목록 파일을 사용하여 FTP 접근을 제어할지 결정합니다. 사용자 목록 파일에 등록된 사용자만 접근하거나, 등록된 사용자를 차단할 수 있습니다.

## 동작 방식

### 활성화 시 (ON)
- 사용자 목록 파일(`/etc/vsftpd.user_list`) 사용
- 목록에 있는 사용자만 접근 허용 또는 차단
- `userlist_deny` 옵션과 함께 사용

### 비활성화 시 (OFF)
- 사용자 목록 파일 무시
- 모든 로컬 사용자 접근 가능 (`local_enable` 활성화 시)

## 사용 시나리오

### 활성화가 유용한 경우
- **제한된 접근**: 특정 사용자만 FTP 접근 허용
- **보안**: 불필요한 사용자 차단
- **관리**: 접근 가능한 사용자 명시적 관리

### 비활성화가 가능한 경우
- **모든 사용자 허용**: 모든 로컬 사용자 접근
- **간단한 설정**: 목록 관리 불필요

## 알아야 할 것들

### 사용자 목록 파일

목록 파일 위치: `/etc/vsftpd.user_list`

파일 형식:
```
user1
user2
user3
```
→ 한 줄에 하나의 사용자명

### userlist_deny 옵션

`userlist_deny` 옵션과 함께 사용:
- **userlist_deny=YES**: 목록에 있는 사용자 차단
- **userlist_deny=NO**: 목록에 있는 사용자만 허용

### 보안 고려사항

**목록에 있는 사용자만 허용** (userlist_deny=NO):
- 더 안전
- 명시적으로 허용한 사용자만 접근

**목록에 있는 사용자 차단** (userlist_deny=YES):
- 특정 사용자만 차단
- 나머지는 모두 허용

## 자주 발생하는 오류

### 사용자 목록 파일이 없음
**원인**: 파일이 생성되지 않음

**해결 방법**:
```bash
# 파일 생성
sudo touch /etc/vsftpd.user_list

# 사용자 추가
echo "username" | sudo tee -a /etc/vsftpd.user_list
```

### 목록에 있는데 접근이 안 됨
**확인 사항**:
1. `userlist_deny` 설정 확인
2. 사용자명이 정확한지 확인
3. 파일 권한 확인

### 목록에 없는데 접근이 안 됨
**원인**: `userlist_deny=NO`로 설정되어 목록에 있는 사용자만 허용

**해결 방법**:
1. 사용자를 목록에 추가
2. 또는 `userlist_deny=YES`로 변경
