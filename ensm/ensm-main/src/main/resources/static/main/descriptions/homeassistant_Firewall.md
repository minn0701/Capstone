# 방화벽 포트 허용 (Firewall)

## 이 옵션이 하는 일

Home Assistant 웹 인터페이스가 사용하는 포트를 시스템 방화벽에서 자동으로 열어주는 기능입니다. 외부에서 Home Assistant에 접속할 수 있도록 합니다.

## 왜 필요한가요?

Home Assistant는 네트워크의 다른 기기(스마트폰, 태블릿 등)에서 접근할 수 있어야 합니다. 방화벽이 포트를 차단하면 클라이언트가 서버에 접속할 수 없습니다.

## 동작 방식

### 활성화 시 (ON)
- TCP 8123 포트 허용 (기본)
- 외부에서 Home Assistant 접속 가능

### 비활성화 시 (OFF)
- 방화벽 규칙 추가 안 됨
- 로컬에서만 접속 가능
- 외부 접근 불가

## 알아야 할 것들

### 보안 고려사항

Home Assistant는 홈 오토메이션을 제어하므로:
- 강력한 비밀번호 사용
- 외부 접속 시 HTTPS 권장
- 방화벽으로 접근 제한 가능

## 자주 발생하는 오류

### 외부에서 접속이 안 됨
**확인 사항**:
1. 방화벽 설정 확인
2. 클라우드 환경: 보안 그룹 확인
3. 라우터 포트 포워딩 확인
