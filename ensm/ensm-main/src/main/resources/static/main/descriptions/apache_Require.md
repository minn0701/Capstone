# 접근 허용 규칙 (Require)

## 이 옵션이 하는 일

특정 디렉토리나 파일에 대한 접근 권한을 제어합니다. 누가 접근할 수 있고 누가 접근할 수 없는지를 지정하는 보안 설정입니다.

## 기본값

- **기본값**: `all granted` (모든 접근 허용)

## 주요 옵션 설명

### all granted
- **의미**: 모든 사용자의 접근을 허용
- **사용 시기**: 공개 웹사이트, 누구나 접근 가능한 콘텐츠
- **예시**: 일반 웹사이트, 블로그, 공개 자료

### all denied
- **의미**: 모든 접근을 차단
- **사용 시기**: 비공개 디렉토리, 임시로 접근 차단
- **예시**: 설정 파일 디렉토리, 백업 폴더

### ip 192.168.1.0/24
- **의미**: 특정 IP 주소 범위만 허용
- **사용 시기**: 내부 네트워크만 접근 가능하게
- **예시**: 관리자 페이지, 내부 도구

### user admin
- **의미**: 특정 사용자만 허용 (인증 필요)
- **사용 시기**: 로그인이 필요한 페이지
- **예시**: 관리자 대시보드, 개인 파일

## 설정 예시

### 공개 웹사이트
```
all granted
```
→ 모든 사람이 접근 가능

### 내부 네트워크만 허용
```
Require ip 192.168.1.0/24
Require ip 10.0.0.0/8
```
→ 192.168.1.x 또는 10.x.x.x IP만 허용

### 특정 IP만 허용
```
Require ip 192.168.1.100
Require ip 203.0.113.50
```
→ 지정한 IP 주소만 허용

### 여러 조건 조합
```
Require all granted
Require not ip 192.168.1.50
```
→ 모든 접근 허용하지만 192.168.1.50은 차단

### 사용자 인증 필요
```
Require valid-user
Require user admin
```
→ 로그인한 사용자만 또는 특정 사용자만

## 알아야 할 것들

### CIDR 표기법

IP 주소 범위를 지정할 때 사용하는 표기법:

- `192.168.1.0/24` → 192.168.1.0 ~ 192.168.1.255 (256개 IP)
- `10.0.0.0/8` → 10.0.0.0 ~ 10.255.255.255 (전체 10.x.x.x)
- `192.168.1.100/32` → 192.168.1.100 하나만

### 여러 규칙 조합

여러 `Require` 지시어를 사용하면 **모든 조건을 만족**해야 접근 가능합니다:

```apache
Require ip 192.168.1.0/24
Require user admin
```
→ 내부 네트워크이면서 동시에 admin 사용자여야 함

### 접근 거부 시

접근이 거부되면 "403 Forbidden" 오류가 발생합니다.

## 자주 발생하는 오류

### "403 Forbidden" 오류
**원인**: 
- `all denied`로 설정됨
- 허용된 IP 범위에 포함되지 않음
- 사용자 인증 실패

**해결 방법**:
1. `all granted`로 변경 (공개 사이트인 경우)
2. 자신의 IP 주소를 허용 목록에 추가
3. 사용자 인증 정보 확인

### 내부 네트워크에서 접속이 안 됨
**확인 사항**:
1. CIDR 표기법이 올바른지 확인
2. 자신의 IP 주소가 허용 범위에 포함되는지 확인
3. 프록시나 VPN을 사용 중이면 실제 IP 주소 확인

### 특정 IP만 차단하고 싶은데
**해결 방법**:
```apache
Require all granted
Require not ip 192.168.1.50
```
→ 모든 접근 허용하지만 특정 IP는 차단

### 로그인 페이지도 차단됨
**원인**: 인증이 필요한 페이지에 `all denied` 설정

**해결 방법**: 인증 페이지는 `all granted`로 설정하고, 인증 후 접근하는 페이지에만 제한을 둡니다.
