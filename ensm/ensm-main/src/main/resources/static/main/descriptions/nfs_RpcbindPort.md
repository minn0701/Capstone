# RPC 포트 (RPCbind Port)

## 이 옵션이 하는 일

RPC(Remote Procedure Call) 바인더가 사용할 포트 번호를 지정합니다. RPC 바인더는 NFS 서비스의 포트 매핑을 관리합니다.

## 기본값

- **기본값**: 111
- **표준 포트**: 111 (RPC 바인더 표준 포트)

## 포트 설정

### 표준 포트 (111)
```
111        → RPC 바인더 기본 포트 (권장)
```
→ 대부분의 경우 이 포트 사용

### 대체 포트
```
1111       → 다른 서비스와 충돌 시
```
→ 특수한 경우에만 사용 (일반적으로 권장하지 않음)

## 알아야 할 것들

### RPC 바인더란?

NFS는 RPC를 사용하여 서비스 간 통신을 합니다:
- RPC 바인더: 포트 매핑 서비스
- NFS 서버: 실제 파일 공유
- Mount 데몬: 마운트 요청 처리

### 포트 매핑

RPC 바인더는 동적 포트를 관리합니다:
- 클라이언트가 RPC 바인더(111)에 질의
- 바인더가 실제 서비스 포트 반환
- 클라이언트가 해당 포트로 연결

### 방화벽 설정

RPC 바인더 포트도 방화벽에서 열어야 합니다:
- TCP/UDP 111: RPC 바인더

## 자주 발생하는 오류

### "RPC: Program not registered" 오류
**원인**: RPC 바인더가 실행되지 않음

**해결 방법**:
1. RPC 서비스 상태 확인: `sudo systemctl status rpcbind`
2. 서비스 시작: `sudo systemctl start rpcbind`
3. 포트 확인

### 포트 충돌
**원인**: 다른 서비스가 111번 포트 사용

**해결 방법**:
1. 포트 사용 확인
2. 다른 서비스 중지
3. 또는 다른 포트 사용 (비권장)
