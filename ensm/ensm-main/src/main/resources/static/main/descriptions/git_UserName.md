# 사용자 이름 (User Name)

## 이 옵션이 하는 일

Git 커밋에 표시될 사용자 이름을 설정합니다. 이 이름은 모든 커밋 기록에 남으며, 누가 변경사항을 만들었는지 추적하는 데 사용됩니다.

## 설정 예시

### 일반적인 이름
```
홍길동
John Doe
김철수
```

### 개발자 이름
```
홍길동 (개발팀)
John Doe - Backend
김철수 [Dev]
```

## 알아야 할 것들

### 전역 vs 로컬 설정

**전역 설정** (이 옵션):
- 모든 Git 저장소에 적용
- `~/.gitconfig`에 저장
- 시스템 전체 기본값

**로컬 설정**:
- 특정 저장소에만 적용
- 저장소별로 다른 이름 사용 가능
- `git config user.name "이름"` (저장소 내에서)

### 커밋에 표시

설정한 이름이 커밋 기록에 표시됩니다:

```
commit abc123
Author: 홍길동 <user@example.com>
Date: Mon Jan 15 10:30:45 2024

    파일 수정
```

### 이메일과의 관계

사용자 이름과 이메일은 함께 사용됩니다:
- 이름: "홍길동"
- 이메일: "user@example.com"
- 커밋: "홍길동 <user@example.com>"

## 자주 발생하는 오류

### 커밋 시 "Please tell me who you are" 오류
**원인**: 사용자 이름 또는 이메일이 설정되지 않음

**해결 방법**:
1. 사용자 이름 설정
2. 이메일 주소도 함께 설정

### 이름이 커밋에 잘못 표시됨
**원인**: 설정이 저장소별로 다르게 설정됨

**해결 방법**:
1. 전역 설정 확인: `git config --global user.name`
2. 로컬 설정 확인: `git config user.name` (저장소 내)
3. 필요시 수정

### 여러 계정 사용 시
**해결 방법**:
- 저장소별로 다른 이름/이메일 설정
- 또는 SSH 키와 함께 사용
