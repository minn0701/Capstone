# WebSocket 포트 (WebSocket Port)

## 이 옵션이 하는 일

noVNC가 VNC 서버와의 실시간 데이터 통신에 사용할 WebSocket 포트 번호를 지정합니다. VNC 화면 데이터는 이 포트를 통해 전송됩니다.

## 기본값

- **기본값**: 6081
- **표준 포트**: 6081 (noVNC WebSocket 기본 포트)

## 포트 설정

### 표준 포트 (6081)
```
6081        → noVNC WebSocket 기본 포트 (권장)
```
→ 대부분의 경우 이 포트 사용

### 대체 포트
```
6082        → 다른 서비스와 충돌 시
9001        → 개발/테스트용
```
→ 특수한 경우에만 사용

## 알아야 할 것들

### WebSocket이란?

웹 브라우저에서 실시간 양방향 통신을 위한 프로토콜:
- HTTP 웹 포트: 초기 연결 및 웹 페이지
- WebSocket 포트: 실시간 VNC 데이터 전송

### 두 포트 모두 필요

noVNC는 두 포트를 모두 사용합니다:
- **웹 포트 (6080)**: 웹 인터페이스 접속
- **WebSocket 포트 (6081)**: VNC 데이터 전송

### 방화벽 설정

두 포트 모두 방화벽에서 열어야 합니다:
- TCP 6080: 웹 인터페이스
- TCP 6081: WebSocket 연결

## 자주 발생하는 오류

### "WebSocket connection failed" 오류
**원인**: 
- WebSocket 포트가 방화벽에서 차단됨
- 포트 설정이 잘못됨

**해결 방법**:
1. WebSocket 포트 설정 확인
2. 방화벽에서 포트 열기
3. 프록시 설정 확인 (있는 경우)

### 웹 페이지는 열리는데 화면이 안 보임
**원인**: WebSocket 연결 실패

**해결 방법**:
1. WebSocket 포트 확인
2. 방화벽 설정 확인
3. 브라우저 콘솔에서 오류 확인

### 포트 충돌
**원인**: 다른 서비스가 같은 포트 사용

**해결 방법**:
1. 포트 사용 확인
2. 다른 포트 사용
3. 또는 충돌하는 서비스 중지
