# 로그 레벨 (LogLevel)

## 이 옵션이 하는 일

Apache가 기록할 로그의 상세 수준을 결정합니다. 로그 레벨이 높을수록 더 많은 정보가 기록되지만, 로그 파일 크기도 커지고 성능에 약간의 영향을 줄 수 있습니다.

## 로그 레벨 설명 (상세한 순서)

### debug
- **의미**: 가장 상세한 디버깅 정보
- **기록 내용**: 모든 요청, 응답, 내부 처리 과정
- **사용 시기**: 문제 해결, 개발 환경
- **주의**: 로그 파일이 매우 커짐, 프로덕션에서는 권장하지 않음

### info
- **의미**: 일반적인 정보성 메시지
- **기록 내용**: 주요 이벤트, 설정 변경, 모듈 로드
- **사용 시기**: 상세한 모니터링이 필요한 경우

### notice
- **의미**: 주목할 만한 이벤트
- **기록 내용**: 중요한 상태 변경, 경고성 이벤트
- **사용 시기**: 일반적인 운영 환경

### warn (권장)
- **의미**: 경고 메시지
- **기록 내용**: 잠재적 문제, 비정상적인 요청
- **사용 시기**: **대부분의 프로덕션 환경에 권장**
- **장점**: 중요한 문제만 기록, 로그 파일 크기 적절

### error
- **의미**: 오류 메시지만
- **기록 내용**: 실제 오류가 발생한 경우만
- **사용 시기**: 로그 파일 크기를 최소화하고 싶을 때

### crit
- **의미**: 심각한 오류만
- **기록 내용**: 시스템에 심각한 영향을 주는 오류
- **사용 시기**: 최소한의 로그만 필요한 경우

### alert
- **의미**: 즉시 조치가 필요한 경고
- **기록 내용**: 매우 중요한 경고만
- **사용 시기**: 특별한 모니터링이 필요한 경우

### emerg
- **의미**: 긴급 상황만
- **기록 내용**: 시스템이 다운될 수 있는 긴급 상황
- **사용 시기**: 극도로 제한적인 로그가 필요한 경우

## 로그 레벨 선택 가이드

### 개발 환경
```
debug 또는 info
```
→ 문제 해결을 위해 상세한 정보 필요

### 일반 웹사이트 (권장)
```
warn
```
→ 중요한 문제만 기록, 로그 파일 크기 적절

### 대용량 트래픽 사이트
```
error 또는 crit
```
→ 로그 파일 크기 최소화, 성능 최적화

### 문제 해결 중
```
debug
```
→ 일시적으로 상세 로그 수집

## 알아야 할 것들

### 로그 파일 크기

로그 레벨이 낮을수록(상세할수록) 로그 파일이 커집니다:

- **debug**: 매우 큼 (수 GB 단위 가능)
- **info**: 큼 (수백 MB ~ 수 GB)
- **warn**: 적절함 (수십 MB ~ 수백 MB)
- **error**: 작음 (수 MB ~ 수십 MB)

### 로그 로테이션

로그 파일이 계속 커지면 디스크 공간을 차지하므로 로그 로테이션을 설정해야 합니다:

```bash
# logrotate 설정 예시
/var/log/apache2/*.log {
    daily
    rotate 7
    compress
    missingok
    notifempty
}
```

### 성능 영향

로그 레벨이 낮을수록(상세할수록) 디스크 I/O가 증가하여 성능에 약간의 영향을 줄 수 있습니다. 대용량 트래픽 사이트에서는 `warn` 이상을 권장합니다.

### 모듈별 로그 레벨

특정 모듈에 대해서만 다른 로그 레벨을 설정할 수 있습니다:

```apache
LogLevel warn
LogLevel info ssl_module  # SSL 모듈만 info 레벨
```

## 자주 발생하는 오류

### 로그 파일이 너무 커짐
**원인**: `debug` 또는 `info` 레벨 사용

**해결 방법**:
1. `warn` 또는 `error` 레벨로 변경
2. 로그 로테이션 설정
3. 오래된 로그 파일 삭제

### 문제 해결을 위한 로그가 부족함
**원인**: `error` 또는 `crit` 레벨 사용

**해결 방법**:
1. 일시적으로 `debug` 또는 `info`로 변경
2. 문제 해결 후 다시 `warn`으로 복원

### 디스크 공간 부족
**원인**: 
- 로그 레벨이 너무 낮음
- 로그 로테이션이 설정되지 않음

**해결 방법**:
1. 로그 레벨을 `warn` 이상으로 변경
2. 로그 로테이션 설정
3. 오래된 로그 파일 삭제:
   ```bash
   sudo find /var/log/apache2 -name "*.log.*" -mtime +30 -delete
   ```

### 로그에 필요한 정보가 없음
**원인**: 로그 레벨이 너무 높음 (`error`, `crit`)

**해결 방법**:
- 문제 해결을 위해 일시적으로 `debug` 또는 `info`로 변경
- 문제 해결 후 원래 레벨로 복원
