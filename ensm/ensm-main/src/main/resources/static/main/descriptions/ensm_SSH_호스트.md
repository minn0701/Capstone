# ENSM SSH 호스트

## 개요

원격 서버의 IP 주소 또는 호스트명을 지정하는 설정입니다. SSH를 통한 원격 실행이 활성화된 경우에만 사용됩니다.

## 설정 방법

원격 서버의 IP 주소 또는 호스트명을 입력합니다:

```
192.168.1.100
```

또는 호스트명:

```
apache-server.example.com
```

## 주요 특징

- **IP 주소**: IPv4 또는 IPv6 주소 사용 가능
- **호스트명**: DNS에 등록된 호스트명 사용 가능
- **네트워크 접근**: ENSM 서버에서 원격 서버로 접근 가능해야 합니다

## 일반적인 사용 예시

```
192.168.1.100
10.0.0.5
apache-server.local
server.example.com
```

## 주의사항

- **네트워크 연결**: ENSM 서버에서 원격 서버로 SSH 접속이 가능해야 합니다
- **방화벽**: 방화벽에서 SSH 포트(기본 22)가 열려있어야 합니다
- **DNS 해석**: 호스트명을 사용하는 경우 DNS 해석이 가능해야 합니다

## 연결 테스트

SSH 연결을 테스트하려면:

```bash
ssh 사용자명@호스트주소
```

또는 포트 지정:

```bash
ssh -p 포트번호 사용자명@호스트주소
```
