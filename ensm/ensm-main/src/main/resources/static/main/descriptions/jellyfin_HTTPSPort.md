# HTTPS 포트 (HTTPS Port)

## 이 옵션이 하는 일

Jellyfin이 HTTPS 암호화 연결에 사용할 포트 번호를 지정합니다. HTTPS가 활성화되어 있을 때만 사용됩니다.

## 기본값

- **기본값**: 8920
- **표준 포트**: 8920 (Jellyfin HTTPS 기본 포트)

## 포트 설정

### 표준 포트 (8920)
```
8920        → Jellyfin HTTPS 기본 포트 (권장)
```
→ 대부분의 경우 이 포트 사용

### 대체 포트
```
8921        → 다른 서비스와 충돌 시
8443        → 일반적인 HTTPS 대체 포트
```
→ 특수한 경우에만 사용

## 알아야 할 것들

### HTTP와 HTTPS 포트

Jellyfin은 두 포트를 모두 사용할 수 있습니다:
- **HTTP 포트**: 8096 (HTTPS 비활성화 시 사용)
- **HTTPS 포트**: 8920 (HTTPS 활성화 시 사용)

### 접속 방법

브라우저에서 접속:
- HTTP: `http://서버주소:8096`
- HTTPS: `https://서버주소:8920`

### 방화벽 설정

HTTPS 사용 시 HTTPS 포트도 방화벽에서 열어야 합니다:
- TCP 8920: HTTPS 연결

## 자주 발생하는 오류

### HTTPS 포트로 접속이 안 됨
**확인 사항**:
1. HTTPS가 활성화되어 있는지 확인
2. 포트 번호가 올바른지 확인
3. 방화벽에서 포트 열기
4. SSL 인증서 설정 확인

### 포트 충돌
**원인**: 다른 서비스가 같은 포트 사용

**해결 방법**:
1. 포트 사용 확인
2. 다른 포트 사용
3. 또는 충돌하는 서비스 중지
