# 디렉토리 목록 표시 (Indexes)

## 이 옵션이 하는 일

웹 디렉토리에 `index.html` 같은 기본 파일이 없을 때, 디렉토리 안의 파일 목록을 웹 브라우저에 표시할지 결정합니다.

## 동작 방식

### 활성화 시 (ON)
- 디렉토리에 `index.html`, `index.php` 등 기본 파일이 없으면
- 디렉토리 안의 모든 파일과 폴더 목록을 웹 페이지로 표시
- 사용자가 파일을 직접 클릭하여 다운로드 가능

### 비활성화 시 (OFF)
- 기본 파일이 없으면 "403 Forbidden" 또는 "404 Not Found" 오류 표시
- 디렉토리 내용이 숨겨짐 (보안상 안전)

## 사용 시나리오

### 활성화가 유용한 경우
- **파일 공유 서버**: 사용자가 파일을 다운로드할 수 있도록
- **개발 환경**: 임시로 파일 목록 확인
- **공개 자료실**: 문서나 미디어 파일 공유

### 비활성화가 권장되는 경우
- **프로덕션 웹사이트**: 보안상 디렉토리 구조 노출 방지
- **민감한 파일**: 실수로 중요한 파일이 노출될 수 있음
- **일반 웹사이트**: 항상 `index.html` 같은 기본 페이지 제공

## 알아야 할 것들

### 기본 파일 우선순위

Apache는 다음 순서로 기본 파일을 찾습니다:
1. `DirectoryIndex` 설정에 지정된 파일들 (기본: `index.html`, `index.php`)
2. 기본 파일이 없고 `Indexes`가 활성화되어 있으면 목록 표시
3. 기본 파일도 없고 `Indexes`도 비활성화되어 있으면 오류

### 보안 고려사항

**Indexes 활성화 시 주의사항**:
- 디렉토리 구조가 노출됨
- 숨겨야 할 파일(설정 파일, 백업 등)이 보일 수 있음
- 파일 이름을 통해 시스템 정보 유출 가능

**보안을 위한 권장사항**:
- 프로덕션 환경에서는 비활성화
- 필요한 디렉토리에만 선택적으로 활성화
- 민감한 파일은 웹 루트 밖에 보관

### 특정 디렉토리만 활성화

모든 디렉토리가 아닌 특정 디렉토리에만 활성화할 수 있습니다:

```apache
<Directory /var/www/html>
    Options -Indexes  # 기본적으로 비활성화
</Directory>

<Directory /var/www/html/downloads>
    Options +Indexes  # downloads 폴더만 활성화
</Directory>
```

## 자주 발생하는 오류

### "403 Forbidden" 오류 (Indexes 비활성화 시)
**원인**: 
- 디렉토리에 `index.html` 같은 기본 파일이 없음
- `Indexes` 옵션이 비활성화됨

**해결 방법**:
1. 해당 디렉토리에 `index.html` 파일 생성
2. 또는 `Indexes` 옵션 활성화 (보안 고려 필요)

### 파일 목록이 보이지 않음
**원인**: 
- `Indexes` 옵션이 비활성화됨
- 기본 파일(`index.html`)이 존재함

**해결 방법**:
- `Indexes` 옵션 활성화
- 또는 기본 파일을 제거/이름 변경

### 민감한 파일이 노출됨
**원인**: `Indexes` 활성화로 인해 모든 파일이 보임

**해결 방법**:
1. 즉시 `Indexes` 비활성화
2. 민감한 파일을 웹 루트 밖으로 이동
3. `.htaccess` 파일로 특정 파일 숨기기:
   ```apache
   IndexIgnore .htaccess *.log *.bak
   ```

### 개발 환경에서는 보이는데 프로덕션에서는 안 보임
**원인**: 서버 설정에서 `Indexes`가 다르게 설정됨

**해결 방법**:
- 각 환경의 Apache 설정 확인
- `.htaccess` 파일로 환경별 설정 가능
