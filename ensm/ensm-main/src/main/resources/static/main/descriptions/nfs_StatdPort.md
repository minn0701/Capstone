# Statd 포트 (Statd Port)

## 이 옵션이 하는 일

NFS Statd(Status Monitor) 데몬이 사용할 포트 번호를 지정합니다. Statd는 파일 잠금 상태를 모니터링합니다.

## 기본값

- **기본값**: 32765
- **일반적인 포트**: 32765

## 포트 설정

### 표준 포트 (32765)
```
32765        → Statd 기본 포트 (권장)
```
→ 대부분의 경우 이 포트 사용

### 대체 포트
```
32766        → 다른 서비스와 충돌 시
```
→ 특수한 경우에만 사용

## 알아야 할 것들

### Statd의 역할

Statd는 다음을 처리합니다:
- 파일 잠금 상태 모니터링
- 서버 재시작 감지
- 클라이언트 알림

### 선택사항

Statd는 필수는 아닙니다:
- 파일 잠금을 사용하지 않으면 불필요
- 하지만 권장됨 (안정성)

### 방화벽 설정

Statd 포트도 방화벽에서 열어야 합니다:
- TCP/UDP 32765: Statd

## 자주 발생하는 오류

### 파일 잠금이 작동하지 않음
**원인**: Statd가 실행되지 않거나 포트가 차단됨

**해결 방법**:
1. Statd 서비스 확인
2. 방화벽에서 포트 열기
3. NFS 서비스 재시작
