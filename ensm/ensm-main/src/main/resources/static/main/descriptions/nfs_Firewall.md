# 방화벽 포트 허용 (Firewall)

## 이 옵션이 하는 일

NFS 서버가 사용하는 모든 포트를 시스템 방화벽에서 자동으로 열어주는 기능입니다. NFS는 여러 포트를 사용하므로 모두 열어야 합니다.

## 왜 필요한가요?

NFS 서버는 네트워크의 다른 컴퓨터에서 접근할 수 있어야 합니다. 방화벽이 포트를 차단하면 NFS 마운트가 실패합니다.

## 동작 방식

### 활성화 시 (ON)
- TCP/UDP 2049: NFS 서버 (메인)
- TCP/UDP 111: RPC 바인더
- TCP/UDP 20048: Mount 데몬
- TCP/UDP 32765-32768: Statd, Lockd 등
- 모든 필요한 포트 자동 허용

### 비활성화 시 (OFF)
- 방화벽 규칙 추가 안 됨
- 로컬에서만 NFS 사용 가능
- 외부 접근 불가

## 알아야 할 것들

### NFS 포트 요구사항

NFS는 여러 포트가 필요합니다:
- **2049**: NFS 서버 (필수)
- **111**: RPC 바인더 (필수)
- **20048**: Mount 데몬 (필수)
- **32765-32768**: 기타 서비스 (선택사항)

### 보안 고려사항

**중요**: NFS는 인증이 약하므로:
- 내부 네트워크에서만 사용 권장
- 외부 접근은 VPN 등으로 보호
- 방화벽으로 접근 제한

### 내부 vs 외부

- **내부 네트워크**: 회사나 가정 네트워크 내부
- **외부 접근**: 인터넷을 통한 접근 (위험)

## 자주 발생하는 오류

### 마운트가 안 됨
**확인 사항**:
1. 모든 필요한 포트가 열려있는지 확인
2. RPC 서비스가 실행 중인지 확인
3. `/etc/exports` 설정 확인

### 방화벽 규칙이 적용되지 않음
**확인 사항**:
1. 방화벽 서비스가 실행 중인지 확인
2. 규칙이 올바르게 추가되었는지 확인
3. 방화벽 재시작 또는 리로드

### 외부에서 접근이 안 됨
**원인**: 보안상 내부 네트워크만 허용되어 있음

**해결 방법**:
- 내부 네트워크에서만 사용하는 것이 권장됨
- 외부 접근이 필요하면 VPN 사용
