# IPv6 수신 주소 (ListenOnV6)

## 이 옵션이 하는 일

BIND DNS 서버가 어떤 IPv6 주소에서 DNS 쿼리를 받을지 지정합니다. IPv6를 지원하는 네트워크에서 DNS 서비스를 제공할 때 사용합니다.

## 기본값

- **기본값**: `::1` (IPv6 localhost만)
- **모든 IPv6 인터페이스**: `any` 또는 `::`

## 설정 예시

### IPv6 localhost만 (기본값)
```
::1
```
→ 로컬 컴퓨터에서만 IPv6 DNS 쿼리 받음

### 모든 IPv6 인터페이스
```
any
:: 
```
→ 모든 IPv6 네트워크 인터페이스에서 수신

### 특정 IPv6 주소
```
2001:db8::1
fe80::1
```
→ 지정한 IPv6 주소에서만 수신

## 알아야 할 것들

### IPv4와 IPv6의 차이

- **IPv4**: `192.168.1.100` (4개의 숫자)
- **IPv6**: `2001:db8::1` (16진수, 콜론으로 구분)

### IPv6 사용 여부

대부분의 환경에서는 IPv4만 사용합니다:
- IPv6를 사용하지 않으면 `::1`로 유지해도 됨
- IPv6 네트워크가 있다면 `any` 또는 특정 주소 지정

### IPv6 주소 확인

```bash
# IPv6 주소 확인
ip -6 addr show

# 또는
ifconfig | grep inet6
```

## 자주 발생하는 오류

### IPv6가 작동하지 않음
**확인 사항**:
1. 시스템이 IPv6를 지원하는지 확인
2. 네트워크 인터페이스에 IPv6 주소가 할당되었는지 확인
3. IPv6가 비활성화되어 있으면 IPv4만 사용해도 됨

### IPv6만 설정했는데 작동 안 함
**원인**: 클라이언트가 IPv4만 사용

**해결 방법**:
- IPv4와 IPv6 모두 설정하는 것이 좋음
- 또는 환경에 맞게 설정
