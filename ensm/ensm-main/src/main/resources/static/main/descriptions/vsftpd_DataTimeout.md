# 데이터 연결 타임아웃 (Data Connection Timeout)

## 이 옵션이 하는 일

파일 전송 중 데이터 연결이 응답하지 않을 때 연결을 끊기까지의 최대 대기 시간(초)을 지정합니다. 느린 네트워크나 문제가 있는 연결을 처리하는 데 사용됩니다.

## 기본값

- **기본값**: 300초 (5분)
- **권장 범위**: 60-600초 (1-10분)

## 설정 예시

### 짧은 타임아웃
```
60         → 1분
120        → 2분
```
→ 빠른 타임아웃, 문제 연결 빠른 종료

### 중간 타임아웃
```
300        → 5분 (기본값)
```
→ 균형잡힌 설정

### 긴 타임아웃
```
600        → 10분
```
→ 느린 네트워크 허용

## 알아야 할 것들

### 데이터 연결이란?

FTP는 두 가지 연결을 사용합니다:
- **제어 연결**: 명령 전송 (포트 21)
- **데이터 연결**: 파일 전송 (PASV 포트)

데이터 연결 타임아웃은 파일 전송 중 문제 발생 시 적용됩니다.

### 느린 네트워크

느린 네트워크 환경에서는:
- 타임아웃을 길게 설정
- 큰 파일 전송 허용
- 네트워크 지연 허용

### 문제 연결 처리

응답하지 않는 연결은:
- 리소스 점유
- 다른 전송 방해
- 타임아웃으로 정리

## 자주 발생하는 오류

### 큰 파일 전송 중 연결이 끊김
**원인**: 타임아웃이 너무 짧음

**해결 방법**:
1. 타임아웃 값 증가 (예: 600초)
2. 네트워크 속도 확인
3. 파일 크기 확인

### 응답하지 않는 연결이 계속 유지됨
**원인**: 타임아웃이 너무 김

**해결 방법**:
1. 타임아웃 값 감소 (예: 300초)
2. 문제 연결 빠른 정리

### 네트워크가 느려서 타임아웃 발생
**해결 방법**:
1. 타임아웃 값 증가
2. 네트워크 속도 개선
3. 또는 파일 크기 줄이기
