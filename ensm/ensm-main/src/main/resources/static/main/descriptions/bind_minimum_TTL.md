# BIND Zone 파일 Minimum TTL

## 개요

Zone 파일의 SOA 레코드에서 음의 캐시(Negative Caching) TTL 값을 지정하는 설정입니다. 존재하지 않는 레코드에 대한 응답을 캐시하는 시간을 의미합니다.

## 설정 방법

SOA 레코드 내에서:

```
@       IN SOA  ns1.example.com. admin.example.com. (
                2024010101
                3600        ; Refresh
                1800        ; Retry
                604800      ; Expire
                86400       ; Minimum TTL (초)
        )
```

## 주요 특징

- **음의 캐시**: 존재하지 않는 레코드 응답 캐시 시간
- **단위**: 초(seconds)
- **권장값**: 3600초(1시간) ~ 86400초(24시간)

## 일반적인 사용 예시

```
; 1시간 음의 캐시
@       IN SOA  ns1.example.com. admin.example.com. (
                2024010101
                3600
                1800
                604800
                3600        ; 1시간
        )

; 24시간 음의 캐시
@       IN SOA  ns1.example.com. admin.example.com. (
                2024010101
                3600
                1800
                604800
                86400       ; 24시간
        )
```

## 음의 캐시 동작

존재하지 않는 레코드에 대한 쿼리:

```
# 존재하지 않는 레코드 쿼리
dig nonexistent.example.com

# 응답: NXDOMAIN (도메인이 존재하지 않음)
# 이 응답이 Minimum TTL 시간 동안 캐시됨
```

## Minimum TTL 선택 가이드

- **일반적**: 3600-86400초 (1시간-24시간)
- **자주 변경**: 레코드가 자주 추가되면 짧게 (3600초)
- **안정적**: 레코드가 안정적이면 길게 (86400초)

## 주의사항

- **$TTL과의 관계**: Zone 파일의 `$TTL`과 일치시키는 것이 좋습니다
- **개별 레코드 TTL**: 개별 레코드에 TTL이 지정되면 그 값이 우선됩니다
- **캐시 시간**: 너무 길면 새로 추가된 레코드가 즉시 반영되지 않을 수 있습니다

## 권장 설정

일반적인 권장 설정:

```
Refresh: 3600 (1시간)
Retry: 1800 (30분)
Expire: 604800 (7일)
Minimum TTL: 86400 (24시간) - $TTL과 일치
```
