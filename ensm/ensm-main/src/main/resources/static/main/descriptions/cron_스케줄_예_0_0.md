# CRON 스케줄

## 개요

CRON 작업의 실행 스케줄을 CRON 형식으로 지정하는 설정입니다. 작업이 실행될 시간과 주기를 정의합니다.

## 설정 방법

CRON 형식으로 스케줄을 지정합니다:

```
0 0 * * *
```

## CRON 형식

CRON 형식은 5개의 필드로 구성됩니다:

```
분 시 일 월 요일
*  *  *  *  *
```

- **분**: 0-59 (분)
- **시**: 0-23 (시)
- **일**: 1-31 (일)
- **월**: 1-12 (월)
- **요일**: 0-7 (요일, 0과 7은 일요일)

## 일반적인 사용 예시

```
# 매분 실행
* * * * *

# 5분마다 실행
*/5 * * * *

# 매시간 정각 실행
0 * * * *

# 매일 자정 실행
0 0 * * *

# 매일 오전 9시 실행
0 9 * * *

# 매주 월요일 자정 실행
0 0 * * 1

# 매월 1일 자정 실행
0 0 1 * *

# 매일 오전 9시 30분 실행
30 9 * * *
```

## CRON 표현식 예시

| 표현식 | 의미 |
|--------|------|
| `* * * * *` | 매분 실행 |
| `*/5 * * * *` | 5분마다 실행 |
| `0 * * * *` | 매시간 정각 실행 |
| `0 0 * * *` | 매일 자정 실행 |
| `0 9 * * *` | 매일 오전 9시 실행 |
| `0 0 * * 1` | 매주 월요일 자정 실행 |
| `0 0 1 * *` | 매월 1일 자정 실행 |
| `30 9 * * 1-5` | 평일 오전 9시 30분 실행 |

## 주의사항

- **시간대**: 시스템의 시간대를 기준으로 실행됩니다
- **정확성**: 분 단위로 실행되므로 초 단위 정확도는 없습니다
- **중복 실행**: 작업이 오래 걸리면 다음 실행과 겹칠 수 있습니다

## 유효성 검사

CRON 표현식이 올바른지 확인하려면:

```bash
# CRON 표현식 테스트
crontab -e
```

또는 온라인 CRON 표현식 검증 도구를 사용할 수 있습니다.
