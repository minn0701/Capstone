# 시간대 (Timezone)

## 이 옵션이 하는 일

Home Assistant가 사용할 시간대를 지정합니다. 자동화 스케줄, 시간 기반 트리거 등에 사용됩니다.

## 기본값

- **기본값**: 시스템 시간대 사용
- **일반적인 설정**: `Asia/Seoul`, `America/New_York` 등

## 설정 예시

### 한국
```
Asia/Seoul
```

### 미국 동부
```
America/New_York
```

### UTC
```
UTC
```

## 알아야 할 것들

### 시간대 형식

IANA 시간대 데이터베이스 형식 사용:
- `대륙/도시` 형식
- 예: `Asia/Seoul`, `America/New_York`, `Europe/London`

### 자동화에 영향

시간대 설정은 다음에 영향을 줍니다:
- 자동화 스케줄
- 시간 기반 트리거
- 로그 타임스탬프

## 자주 발생하는 오류

### 시간이 잘못 표시됨
**원인**: 시간대 설정 오류

**해결 방법**:
1. 올바른 시간대 설정
2. 시스템 시간대 확인
3. Home Assistant 재시작
