# Push 기본 동작 (Push Default)

## 이 옵션이 하는 일

`git push` 명령어 실행 시 브랜치를 푸시하는 기본 동작을 지정합니다. 여러 브랜치를 관리할 때 유용합니다.

## 선택지 설명

### simple (권장)
- **의미**: 현재 브랜치만 푸시, 이름이 같은 원격 브랜치에만
- **효과**: 안전하고 예측 가능
- **사용 시기**: **대부분의 경우 권장**

### current
- **의미**: 현재 브랜치를 같은 이름의 원격 브랜치에 푸시
- **효과**: simple과 유사하지만 업스트림 설정 불필요
- **사용 시기**: 간단한 워크플로우

### upstream
- **의미**: 현재 브랜치를 설정된 업스트림 브랜치에 푸시
- **효과**: 업스트림 설정 필요
- **사용 시기**: 업스트림 브랜치가 명확한 경우

### matching
- **의미**: 로컬과 원격의 같은 이름 브랜치 모두 푸시
- **효과**: 여러 브랜치 동시 푸시
- **주의**: 실수로 모든 브랜치 푸시 가능 (위험)

### nothing
- **의미**: 기본 푸시 동작 없음, 항상 브랜치 명시 필요
- **효과**: 가장 안전
- **사용 시기**: 실수 방지가 중요한 경우

## 알아야 할 것들

### 업스트림 브랜치

업스트림 브랜치는 다음과 같이 설정됩니다:
```bash
git push -u origin main
```
→ `main` 브랜치의 업스트림을 `origin/main`으로 설정

### 안전한 설정

**simple (권장)**:
- 현재 브랜치만 푸시
- 이름이 같은 원격 브랜치에만
- 실수 방지

**matching (위험)**:
- 모든 브랜치 푸시
- 실수로 모든 브랜치 푸시 가능
- 주의 필요

## 자주 발생하는 오류

### "The current branch has no upstream branch" 오류
**원인**: 업스트림 브랜치가 설정되지 않음

**해결 방법**:
1. `git push -u origin <branch-name>` 사용
2. 또는 `push.default`를 `current`로 변경

### 실수로 모든 브랜치 푸시됨
**원인**: `push.default`가 `matching`으로 설정됨

**해결 방법**:
1. `push.default`를 `simple`로 변경 (권장)
2. 또는 `nothing`으로 설정

### 푸시가 안 됨
**확인 사항**:
1. `push.default` 설정 확인
2. 업스트림 브랜치 설정 확인
3. 원격 저장소 권한 확인
