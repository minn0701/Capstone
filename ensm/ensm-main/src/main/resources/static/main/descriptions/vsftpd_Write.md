# 파일 쓰기 권한 (Write Enable)

## 이 옵션이 하는 일

FTP 클라이언트가 파일을 업로드하거나 수정, 삭제할 수 있게 할지 결정합니다. 활성화하면 사용자가 서버에 파일을 쓸 수 있습니다.

## 동작 방식

### 활성화 시 (ON)
- 파일 업로드 가능
- 파일 수정 가능
- 파일 삭제 가능
- 디렉토리 생성/삭제 가능

### 비활성화 시 (OFF)
- 읽기 전용 접근
- 파일 다운로드만 가능
- 업로드, 수정, 삭제 불가

## 사용 시나리오

### 활성화가 필요한 경우
- **파일 업로드 서비스**: 사용자가 파일을 업로드해야 함
- **웹 호스팅**: 웹사이트 파일 관리
- **파일 공유**: 사용자 간 파일 교환

### 비활성화가 권장되는 경우
- **읽기 전용 서버**: 다운로드만 제공
- **보안**: 불필요한 쓰기 권한 차단
- **공개 자료실**: 배포용 파일만 제공

## 알아야 할 것들

### 디렉토리 권한

쓰기 권한을 사용하려면 디렉토리에 쓰기 권한이 필요합니다:

```bash
# 사용자 홈 디렉토리 쓰기 권한
sudo chmod 755 /home/username
sudo chown username:username /home/username

# 특정 디렉토리만 쓰기 허용
sudo chmod 775 /home/username/uploads
```

### 보안 고려사항

**주의사항**:
- 업로드된 파일 검사 필요
- 디스크 공간 모니터링
- 악성 파일 업로드 방지

**안전한 설정**:
- 특정 디렉토리만 쓰기 허용
- 파일 타입 제한
- 디스크 할당량 설정

### chroot와의 관계

`chroot_local_user` 활성화 시:
- 사용자는 자신의 홈 디렉토리로 제한됨
- 그 안에서만 쓰기 가능
- 보안 강화

## 자주 발생하는 오류

### "550 Permission denied" 오류 (업로드 시)
**원인**: 
- `write_enable`이 비활성화됨
- 디렉토리 쓰기 권한이 없음

**해결 방법**:
1. `write_enable` 활성화
2. 디렉토리 권한 확인 및 수정
3. 소유권 확인

### 파일을 업로드했는데 보이지 않음
**확인 사항**:
1. 업로드 디렉토리 확인
2. 파일 권한 확인
3. 디스크 공간 확인

### 디스크 공간 부족
**원인**: 대용량 파일 업로드

**해결 방법**:
1. 디스크 할당량 설정
2. 오래된 파일 정리
3. 업로드 파일 크기 제한
