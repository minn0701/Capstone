# DNS 포워더 주소 (Forwarders)

## 이 옵션이 하는 일

BIND가 자신이 모르는 도메인에 대한 쿼리를 전달할 다른 DNS 서버의 IP 주소를 지정합니다. 여러 포워더를 지정하면 로드 밸런싱과 장애 대응이 가능합니다.

## 기본값

- **기본값**: 없음 (루트 DNS 서버 직접 사용)
- **일반적인 설정**: `8.8.8.8; 8.8.4.4;` (Google DNS)

## 설정 예시

### Google DNS
```
8.8.8.8; 8.8.4.4;
```
→ Google의 공용 DNS 서버

### Cloudflare DNS
```
1.1.1.1; 1.0.0.1;
```
→ Cloudflare의 공용 DNS 서버 (빠름)

### 여러 포워더 조합
```
8.8.8.8; 8.8.4.4; 1.1.1.1; 1.0.0.1;
```
→ 여러 DNS 서버 사용 (로드 밸런싱)

### ISP DNS
```
203.248.252.2; 203.248.252.3;
```
→ 인터넷 제공업체의 DNS 서버

### 내부 DNS 서버
```
192.168.1.10; 192.168.1.11;
```
→ 회사 내부의 다른 DNS 서버

## 알아야 할 것들

### 포워더 선택 기준

**속도**:
- Cloudflare (1.1.1.1): 매우 빠름
- Google (8.8.8.8): 빠름
- ISP DNS: 지역에 따라 다름

**프라이버시**:
- Cloudflare: 로그 보관 최소화
- Google: 일부 로그 수집
- ISP DNS: 로그 수집 가능

**안정성**:
- 여러 포워더 지정 권장
- 하나가 다운되어도 다른 것으로 폴백

### 포워더 형식

- **IP 주소**: `8.8.8.8`
- **세미콜론 구분**: `8.8.8.8; 8.8.4.4;`
- **공백**: 선택사항 (가독성)

### 포워더 없이 사용

포워더를 지정하지 않으면:
- 루트 DNS 서버에 직접 질의
- 느릴 수 있지만 중간 서버 없이 직접 통신

## 자주 발생하는 오류

### DNS 쿼리가 느림
**원인**: 포워더가 느리거나 멀리 있음

**해결 방법**:
1. 빠른 포워더로 변경 (예: 1.1.1.1)
2. 여러 포워더 지정 (로드 밸런싱)
3. 지역에 가까운 DNS 서버 사용

### 포워더가 응답하지 않음
**원인**: 포워더 서버 다운 또는 네트워크 문제

**해결 방법**:
1. 여러 포워더 지정 (자동 폴백)
2. 포워더 서버 상태 확인
3. 네트워크 연결 확인

### 특정 도메인이 안 됨
**확인 사항**:
1. 포워더가 해당 도메인을 알고 있는지
2. Zone 파일에 정의되어 있는지
3. DNS 전파 시간 대기
