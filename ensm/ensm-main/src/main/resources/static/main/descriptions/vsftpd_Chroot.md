# 사용자 홈 디렉토리 제한 (Chroot Local User)

## 이 옵션이 하는 일

로컬 사용자를 자신의 홈 디렉토리로 제한합니다. 사용자가 상위 디렉토리나 시스템 다른 부분에 접근하는 것을 방지하여 보안을 강화합니다.

## 동작 방식

### 활성화 시 (ON, 권장)
- 사용자는 자신의 홈 디렉토리만 접근 가능
- 상위 디렉토리(`/`, `/etc` 등) 접근 불가
- 보안 강화

### 비활성화 시 (OFF)
- 사용자가 전체 파일 시스템 탐색 가능
- 보안 위험 증가
- 권장하지 않음

## 사용 시나리오

### 활성화가 권장되는 경우 (대부분)
- **모든 FTP 서버**: 보안상 필수
- **웹 호스팅**: 사용자 간 격리
- **파일 공유**: 각 사용자 영역 분리

### 비활성화가 필요한 경우
- **특수한 구성**: 시스템 전체 접근이 필요한 경우 (드물음)
- **레거시 애플리케이션**: 오래된 소프트웨어 호환성

## 알아야 할 것들

### chroot란?

"change root"의 약자로, 사용자의 루트 디렉토리를 변경합니다:
- 실제 루트(`/`) 대신 홈 디렉토리를 루트로 인식
- 상위 디렉토리 접근 불가
- 보안 격리

### 홈 디렉토리 권한

chroot를 사용하려면 홈 디렉토리에 적절한 권한이 필요합니다:

```bash
# 홈 디렉토리 권한 설정
sudo chmod 755 /home/username
sudo chown username:username /home/username
```

### allow_writeable_chroot와의 관계

chroot 활성화 시:
- 기본적으로 홈 디렉토리는 쓰기 불가 (보안)
- `allow_writeable_chroot` 활성화 시 쓰기 가능
- 보안과 편의성의 균형

## 자주 발생하는 오류

### "500 OOPS: vsftpd: refusing to run with writable root inside chroot()"
**원인**: chroot된 디렉토리가 쓰기 가능함

**해결 방법**:
1. 홈 디렉토리를 읽기 전용으로 변경: `chmod 555 /home/username`
2. 또는 `allow_writeable_chroot` 활성화
3. 하위 디렉토리에만 쓰기 권한 부여

### 사용자가 상위 디렉토리에 접근하려고 함
**원인**: chroot가 비활성화됨

**해결 방법**:
1. `chroot_local_user` 활성화
2. 보안상 권장

### 홈 디렉토리 밖의 파일에 접근 불가
**원인**: chroot가 정상 작동 중 (의도된 동작)

**설명**: 
- 이것은 보안 기능입니다
- 사용자는 자신의 홈 디렉토리만 접근해야 합니다
- 다른 파일이 필요하면 심볼릭 링크 사용
