# SSL/TLS 암호화 (SSL Enable)

## 이 옵션이 하는 일

noVNC 웹 인터페이스에 SSL/TLS 암호화 연결을 사용할지 결정합니다. 활성화하면 데이터가 암호화되어 보안이 강화됩니다.

## 동작 방식

### 활성화 시 (ON, 권장)
- HTTPS 연결 사용
- 데이터 암호화
- 보안 강화
- SSL 인증서 필요

### 비활성화 시 (OFF)
- HTTP 연결만 사용
- 데이터 암호화 안 됨
- 내부 네트워크에서만 사용 권장

## 사용 시나리오

### 활성화가 권장되는 경우
- **외부 접속**: 인터넷을 통한 접속
- **보안**: VNC 데이터 암호화
- **프로덕션 환경**: 실제 사용 환경

### 비활성화가 가능한 경우
- **내부 네트워크만**: 로컬 네트워크에서만 접속
- **개발 환경**: 테스트 목적

## 알아야 할 것들

### SSL 인증서 필요

SSL을 사용하려면 인증서가 필요합니다:
- **자체 서명 인증서**: 개발/테스트용
- **Let's Encrypt**: 무료 공인 인증서 (권장)
- **상용 인증서**: 유료 인증서

### VNC와 SSL

noVNC의 SSL은 웹 연결만 암호화합니다:
- 웹 브라우저 ↔ noVNC 서버: SSL 암호화
- noVNC 서버 ↔ VNC 서버: 일반 연결 (VNC 서버에서 SSL 설정 가능)

## 자주 발생하는 오류

### "SSL connection failed" 오류
**원인**: 
- 인증서가 없음
- 인증서 경로가 잘못됨

**해결 방법**:
1. 인증서 생성 또는 설치
2. 인증서 경로 확인
3. 권한 설정

### 브라우저에서 SSL 오류
**원인**: 자체 서명 인증서 사용

**해결 방법**:
1. 브라우저에서 인증서 예외 추가
2. 또는 공인 인증서 사용
