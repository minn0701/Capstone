# SSH 키 주석

## 개요

SSH 키에 포함될 주석을 지정하는 설정입니다. 키를 식별하는 데 사용되며, 일반적으로 사용자명과 호스트명을 포함합니다.

## 설정 방법

키 주석을 입력합니다:

```
user@hostname
```

## 주요 특징

- **식별**: 키를 식별하는 데 사용
- **자유 형식**: 원하는 형식으로 지정 가능
- **선택사항**: 주석은 선택사항이지만 권장됩니다

## 일반적인 사용 예시

```
user@hostname
user@example.com
admin@server
mykey@mymachine
```

## 권장 형식

일반적으로 다음 형식을 사용합니다:

```
사용자명@호스트명
```

예:
- `admin@server1`
- `user@example.com`
- `root@production-server`

## 주의사항

- **특수문자**: 특수문자 사용 시 따옴표로 감싸야 할 수 있습니다
- **길이**: 너무 긴 주석은 가독성을 떨어뜨릴 수 있습니다
- **식별성**: 여러 키를 관리할 때 구분하기 쉬운 주석을 사용하세요

## 주석의 용도

SSH 키 주석은 다음 용도로 사용됩니다:

1. **키 식별**: 여러 키 중에서 원하는 키를 찾기
2. **관리**: 키의 용도나 소유자를 표시
3. **디버깅**: 키 사용 시 로그에 표시됨

## 예시

```bash
# 주석이 포함된 공개키
ssh-rsa AAAAB3NzaC1yc2EAAAADAQABAAACAQ... user@hostname
```

공개키 파일(`~/.ssh/id_rsa.pub`)에 주석이 포함되어 있습니다.
