# VNC 비밀번호 (VNC Password)

## 이 옵션이 하는 일

VNC 서버에 연결할 때 사용할 비밀번호를 지정합니다. VNC 서버의 비밀번호와 일치해야 합니다.

## 기본값

- **기본값**: 없음 (설정 필요)
- **형식**: 텍스트 문자열

## 설정 예시

### 강력한 비밀번호
```
MySecurePassword123!
```
→ 복잡한 비밀번호 권장

### 간단한 비밀번호
```
password
```
→ 개발/테스트용 (프로덕션에서는 권장하지 않음)

## 알아야 할 것들

### VNC 서버 비밀번호

noVNC는 VNC 서버에 연결하는 클라이언트입니다:
- VNC 서버의 비밀번호와 일치해야 함
- VNC 서버에서 비밀번호 설정 필요

### 보안 고려사항

**중요**: VNC 비밀번호는:
- 강력한 비밀번호 사용 권장
- 평문으로 저장될 수 있음 (주의)
- 정기적으로 변경 권장

### 비밀번호 설정

VNC 서버에서 비밀번호 설정:
```bash
# TigerVNC
vncpasswd

# RealVNC
vncserver -passwd
```

## 자주 발생하는 오류

### "Authentication failed" 오류
**원인**: 비밀번호가 일치하지 않음

**해결 방법**:
1. VNC 서버 비밀번호 확인
2. noVNC 설정의 비밀번호 확인
3. 비밀번호 재설정

### 비밀번호가 저장되지 않음
**확인 사항**:
1. 설정 저장 확인
2. 서비스 재시작
3. 설정 파일 확인
