# Mount 데몬 포트 (Mountd Port)

## 이 옵션이 하는 일

NFS Mount 데몬이 사용할 포트 번호를 지정합니다. Mount 데몬은 클라이언트의 마운트 요청을 처리합니다.

## 기본값

- **기본값**: 20048
- **일반적인 포트**: 20048

## 포트 설정

### 표준 포트 (20048)
```
20048        → Mount 데몬 기본 포트 (권장)
```
→ 대부분의 경우 이 포트 사용

### 대체 포트
```
20049        → 다른 서비스와 충돌 시
```
→ 특수한 경우에만 사용

## 알아야 할 것들

### Mount 데몬의 역할

Mount 데몬은 다음을 처리합니다:
- 마운트 요청 처리
- 마운트 포인트 확인
- 접근 권한 검증

### RPC와의 관계

Mount 데몬도 RPC를 사용합니다:
- RPC 바인더(111)에 등록
- 클라이언트가 바인더를 통해 포트 확인
- 해당 포트로 마운트 요청

### 방화벽 설정

Mount 데몬 포트도 방화벽에서 열어야 합니다:
- TCP/UDP 20048: Mount 데몬

## 자주 발생하는 오류

### 마운트 요청이 실패함
**원인**: 
- Mount 데몬이 실행되지 않음
- 포트가 방화벽에서 차단됨

**해결 방법**:
1. NFS 서비스 상태 확인
2. 방화벽에서 포트 열기
3. 서비스 재시작

### 포트 충돌
**원인**: 다른 서비스가 같은 포트 사용

**해결 방법**:
1. 포트 사용 확인
2. 다른 포트 사용
3. 또는 충돌하는 서비스 중지
