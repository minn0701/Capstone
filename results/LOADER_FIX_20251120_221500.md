# Spring Boot Loader 문제 해결

**생성일시**: 2025-11-20 22:15:00

## 문제 확인

1. ✅ JAR 파일 무결성: 정상
2. ✅ 중첩된 JAR 파일들: 모두 정상 (37개)
3. ❌ Spring Boot Loader 실행 시 `NegativeArraySizeException: -12167` 발생

## 원인

Spring Boot 3.2.0에서 중첩된 JAR 파일 처리 방식이 변경되었습니다. 새로운 로더 구현에서 Java 21 환경에서 버그가 발생할 수 있습니다.

## 해결 방법

### CLASSIC 로더 사용

Spring Boot 3.2.0의 새로운 로더 구현 대신 기존 CLASSIC 로더를 사용하도록 설정했습니다.

### 적용된 변경사항

#### `ensm/ensm-main/build.gradle`
```groovy
bootJar {
    loaderImplementation = 'CLASSIC'
}
```

#### `ensm/ensm-auth/build.gradle`
```groovy
bootJar {
    loaderImplementation = 'CLASSIC'
}
```

## 다음 단계

1. **완전한 재빌드**:
   ```bash
   cd ensm
   gradlew clean
   .\build-for-rpm.bat
   ```

2. **리눅스 서버에 재배포**:
   ```bash
   cd ensm-rpm
   ./build-and-deploy.sh
   ```

3. **서비스 재시작**:
   ```bash
   sudo systemctl restart ensm-main.service
   sudo systemctl status ensm-main.service
   ```

## 예상 결과

CLASSIC 로더를 사용하면 `NegativeArraySizeException` 오류가 해결되고 정상적으로 실행될 것입니다.

## 참고

- CLASSIC 로더는 Spring Boot 3.2.0 이전에 사용되던 안정적인 로더입니다
- 새로운 로더 구현의 성능 향상은 있지만, 현재 환경에서는 CLASSIC 로더가 더 안정적입니다
- 향후 Spring Boot 버전 업그레이드 시 새로운 로더 구현의 버그가 수정되면 다시 시도할 수 있습니다
