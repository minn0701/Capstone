### 실행 흐름
```
Java 백엔드 (ensm 사용자)
  ↓
run_script (C 바이너리, setuid 4755, root 소유)
  ↓ (root 권한으로 실행됨)
쉘 스크립트 (manage_packages.sh 등)
  ↓
실제 명령어 실행 (dnf install, systemctl enable 등, root 권한)
```

- `run_script.c`는 보안을 위해 `/usr/local/bin/ensm-scripts/` 하위 스크립트만 실행 가능
