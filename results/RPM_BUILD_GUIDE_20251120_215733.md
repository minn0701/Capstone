# RPM 빌드 가이드

**생성일시**: 2025-11-20 21:57:33

## 문제 상황

리눅스에서 RPM 빌드 시 다음 오류 발생:
```
cp: cannot stat '/root/rpmbuild/SOURCES/ensm-auth-0.0.1-SNAPSHOT.jar': No such file or directory
```

## 원인

Windows에서 빌드한 JAR 파일이 리눅스의 `SOURCES` 디렉토리에 없음

## 해결 방법

### 1. Windows에서 빌드 완료 확인

Windows에서 다음 명령어 실행:
```cmd
cd C:\Users\HM_LT\Desktop\Capstone\ensm
.\build-for-rpm.bat
```

빌드 완료 후 다음 파일들이 생성되어야 합니다:
- `ensm-rpm/SOURCES/ensm-auth-0.0.1-SNAPSHOT.jar`
- `ensm-rpm/SOURCES/ensm-main-0.0.1-SNAPSHOT.jar`
- `ensm-rpm/SOURCES/ensm-scripts/` (폴더 전체)

### 2. 리눅스로 파일 복사

#### 방법 1: 전체 ensm-rpm 폴더 복사 (권장)
```bash
# Windows에서 압축
# PowerShell에서:
Compress-Archive -Path ensm-rpm -DestinationPath ensm-rpm.zip

# 리눅스로 전송 후:
cd /root
unzip ensm-rpm.zip
cd ensm-rpm
rpmbuild -ba SPECS/ensm.spec
```

#### 방법 2: SOURCES 폴더만 복사
```bash
# Windows에서 SOURCES 폴더 압축
# PowerShell에서:
Compress-Archive -Path ensm-rpm\SOURCES -DestinationPath SOURCES.zip

# 리눅스로 전송 후:
mkdir -p /root/rpmbuild/SOURCES
cd /root/rpmbuild/SOURCES
unzip SOURCES.zip
# 또는 직접 복사:
# scp -r SOURCES/* root@linux-server:/root/rpmbuild/SOURCES/

# SPECS 파일도 복사
cd /root
mkdir -p ensm-rpm/SPECS
# SPECS 파일 복사 후:
cd ensm-rpm
rpmbuild -ba SPECS/ensm.spec
```

#### 방법 3: 직접 파일 복사 (scp 사용)
```bash
# Windows에서 (PowerShell 또는 WSL):
scp ensm-rpm/SOURCES/ensm-auth-0.0.1-SNAPSHOT.jar root@linux-server:/root/rpmbuild/SOURCES/
scp ensm-rpm/SOURCES/ensm-main-0.0.1-SNAPSHOT.jar root@linux-server:/root/rpmbuild/SOURCES/
scp -r ensm-rpm/SOURCES/ensm-scripts root@linux-server:/root/rpmbuild/SOURCES/
scp -r ensm-rpm/SOURCES/systemd root@linux-server:/root/rpmbuild/SOURCES/
scp -r ensm-rpm/SOURCES/prometheus root@linux-server:/root/rpmbuild/SOURCES/
scp -r ensm-rpm/SOURCES/loki root@linux-server:/root/rpmbuild/SOURCES/
scp -r ensm-rpm/SOURCES/promtail root@linux-server:/root/rpmbuild/SOURCES/
scp -r ensm-rpm/SOURCES/dependencies root@linux-server:/root/rpmbuild/SOURCES/
```

### 3. 리눅스에서 빌드 전 확인

```bash
# SOURCES 디렉토리 확인
ls -la /root/rpmbuild/SOURCES/

# 필수 파일 확인
ls -lh /root/rpmbuild/SOURCES/ensm-auth-0.0.1-SNAPSHOT.jar
ls -lh /root/rpmbuild/SOURCES/ensm-main-0.0.1-SNAPSHOT.jar
ls -ld /root/rpmbuild/SOURCES/ensm-scripts

# SPECS 파일 확인
ls -la /root/ensm-rpm/SPECS/ensm.spec
```

### 4. RPM 빌드 실행

```bash
cd /root/ensm-rpm
rpmbuild -ba SPECS/ensm.spec
```

## 필수 파일 목록

빌드 전에 다음 파일들이 `/root/rpmbuild/SOURCES/`에 있어야 합니다:

### JAR 파일
- `ensm-auth-0.0.1-SNAPSHOT.jar`
- `ensm-main-0.0.1-SNAPSHOT.jar`

### 스크립트 폴더
- `ensm-scripts/` (전체 폴더)

### 설정 파일
- `systemd/` (전체 폴더)
- `prometheus/` (전체 폴더)
- `loki/` (전체 폴더)
- `promtail/` (전체 폴더)
- `dependencies/` (전체 폴더)

## 문제 해결 체크리스트

- [ ] Windows에서 `build-for-rpm.bat` 실행 완료
- [ ] `ensm-rpm/SOURCES/` 폴더에 JAR 파일 존재 확인
- [ ] `ensm-rpm/SOURCES/ensm-scripts/` 폴더 존재 확인
- [ ] 리눅스로 파일 복사 완료
- [ ] `/root/rpmbuild/SOURCES/` 또는 `ensm-rpm/SOURCES/`에 파일 존재 확인
- [ ] `rpmbuild -ba SPECS/ensm.spec` 실행

## 참고

- `rpmbuild`는 기본적으로 `/root/rpmbuild/SOURCES/`를 사용합니다
- `ensm-rpm` 폴더에서 직접 빌드하려면 `rpmbuild` 명령에 `--define` 옵션을 사용하거나
- `ensm-rpm` 폴더를 `/root/rpmbuild/`로 복사하거나
- `~/.rpmmacros` 파일에서 경로를 설정할 수 있습니다
